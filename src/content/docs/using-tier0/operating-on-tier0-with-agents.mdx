Connect your AI agent to Tier0 through MCP. The agent can find and use platform APIs within the permissions you grant.

<AgentIcons />

:::note[Before you start]
- Get the MCP URL from **Settings** > **MCP Access**.
- Your agent client must support remote MCP over HTTP.
:::

## Connecting Agent

:::note
Codex is used as an example.
:::
<Tabs syncKey="edition">
  <TabItem label="Manually Add">
    1. Add an MCP server in **Settings** > **Plugin** > **MCP** using the URL from Tier0.
    2. Add a personal API key in Tier0 under **Settings** > **API Keys** > **Personal Keys** with the required permission level.
    3. Enter the personal API key in the MCP server you added in Codex.
        ```json
        {
          "Authorization": "Bearer <your-personal-api-key>",
        }
        ```
    4. Ask the agent to use `whoami` to check the connection.
 </TabItem>
  <TabItem label="Command Line">
   1. Run the following command in your powershell and log in on the browser.
      ```bash
      codex mcp add tier0 --url https://your-tier0-url/mcp --oauth-client-registration dcr
      ```
  2. Run the following command to authorize workspace and grant corresponding permissions on browser.
      ```bash
      codex mcp login tier0 --oauth-client-registration dcr
      ```
  3. Ask the agent to use `whoami` to check the connection.
    </TabItem>
</Tabs>



## Operating on Tier0 with Agent

- MCP tools:

  | Tool | Use |
  | --- | --- |
  | `whoami` | Check your identity and permissions. |
  | `docs` | Read API documentation. |
  | `search` | Find an API operation. |
  | `execute` | Call an API operation. |

- Usage

  1. Ask your agent to use `docs` and `search` to find the API operation you want to call.
  3. Use `execute` to call the API operation.

For example:
```text
Read the current value of `Plant/Line1/Metric/Temperature` in my workspace.
```
:::tip[If failed to get results]
After a write operation, ask the agent to read the result back. If the result says `outcome=unknown`, check the current state before retrying.
:::
