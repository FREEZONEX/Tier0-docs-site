In a real factory, data is often collected by edge devices and managed from a central node to reduce network bandwidth usage and improve data security.
Tier0 provides a fleet management solution to manage data on edge nodes from a central node.

## Connecting Edge Nodes to the Center

<Steps>
1. Create fleet nodes on the central node first.

        :::note
        The number of edge nodes that can be connected depends on the license.
        :::
2. Use the token generated by the central node to connect each edge node.
</Steps>

## Syncing Data between Edge and Center

- UNS data can be selected and synced only from edge nodes to the central node. Once synced, both history and real-time data of the selected topics will be available on the central node.
- From the central node, you can assign users or user groups to edge nodes for node management.

:::note
Set application access permission to user groups on the central node first, so that users in the group can access allowed applications on edge nodes.
:::
