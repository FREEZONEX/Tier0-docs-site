With Tier0 edge-center collaboration, you can collect data on edge devices, and manage it on the center platform.
- Edge device: Tier0 Edge or Tier0 Enterprise on an edge node.
- Center platform: Tier0 Cloud or Tier0 Enterprise on a center node.

## Connecting Edge Nodes to the Center

<Tabs syncKey="edition">
  <TabItem label="Enterprise">
    <Steps>
    1. Create fleet nodes on the central node first.

            :::note
            The number of edge nodes that can be connected depends on the license.
            :::
    2. Use the token generated by the central node to connect each edge node.
    </Steps>
  </TabItem>
  <TabItem label="Cloud">
    <Steps>
    1. Download Tier0 Edge from Tier0 Cloud according to the operating system.
    2. Go through authentication and complete the connection between edge and cloud.
    </Steps>
  </TabItem>
</Tabs>

## Syncing Data between Edge and Center

<Tabs syncKey="edition">
  <TabItem label="Enterprise">
    - Namespace Tables can be selected and synced only from edge nodes to the central node. Once synced, both history and real-time data of the selected Tables will be available on the central node.
    - From the central node, you can assign users or user groups to edge nodes for node management.

    :::note
    Set application access permission to user groups on the central node first, so that users in the group can access allowed applications on edge nodes.
    :::
  </TabItem>
  <TabItem label="Cloud">
    - Schemas of Namespace Tables are synced from Edge to Cloud by default once connected.
    - Only selected Tables whose records will be synced to Cloud.
    - From the central node, you can assign users or user groups to edge nodes for node management.

    :::tip[To connect data on Edge with no independent agent]
    Once connected, you can ask agent on Cloud to connect data sources and build streams to obtain and process data on Edge.
    :::
  </TabItem>
</Tabs>
