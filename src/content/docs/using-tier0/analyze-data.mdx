Tier0 uses Marimo Notebook for advanced data analysis with **Python** scripts.

:::tip[Know before you start]
Data connected to UNS models with **Enable History** selected is available as an existing data source in **Notebook**.
:::
<Steps>
1. UNS data is under **VARIABLES** > **PostgreSQL** > **tenant_id** > **uns**.
2. Use **@** to include data sources when you **GENERATE WITH AI**, and fuzzy match is available for data sources searching.
3. Save versions of your analysis for future rollbacks.
</Steps>

:::tip[AI assist in Notebook]
- AI assist is available in Tier0 Cloud.
- You need to provide key for AI assist in Tier0 Enterprise.
:::
