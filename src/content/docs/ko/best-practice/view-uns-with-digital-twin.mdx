Tier0의 digital twin 기능을 사용하면 실제와 같은 3D 장면과 모델에서 UNS 데이터를 실시간으로 볼 수 있습니다.

## 공장 씬 시각화
<Steps>
1. **Model**에 모델을 업로드한 뒤, 실시간 동작에 사용할 UNS 데이터 매핑 노드를 선택합니다.
2. 서로 다른 UNS 데이터를 가진 인스턴스를 모델에 추가해 여러 기계를 시뮬레이션합니다.
3. **Scene**에서 **Instance Library**의 인스턴스를 씬에 추가합니다.
4. 상단 도구로 모델을 이동, 확대/축소, 회전해 씬에 맞추고 시점과 좌표 위치를 조정합니다.
5. **Object**에서 모델 위치와 바인딩된 UNS 데이터를 확인합니다.
</Steps>
