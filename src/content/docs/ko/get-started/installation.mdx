Tier0는 세 가지 에디션으로 제공됩니다.
- **Cloud** - 인프라를 직접 운영할 필요가 없는 관리형 SaaS입니다.
- **Enterprise** - 기업 환경을 위한 프라이빗 배포판입니다.
- **Edge** - Docker를 사용해 로컬에서 실행하는 오픈 소스 버전입니다.

어떤 edition을 선택해야 할지 확실하지 않다면 [최적의 버전 선택](../choosing-the-best-product/)을 먼저 확인하세요.

## Tier0 설치

<Tabs syncKey="edition">
  <TabItem label="Cloud">

    Tier0 Cloud를 사용하려면 먼저 체험 계정을 신청하세요.
    <Steps>
		1. [Register Tier0](https://tier0.dev/signup)에서 계정을 등록합니다.
		2. 이메일로 받은 인증 코드로 확인하고 등록한 계정으로 로그인합니다.
		3. Workspace를 만들고 체험을 시작합니다.
	</Steps>

  </TabItem>
  <TabItem label="Enterprise">

    #### 요구사항
    - 단일 노드 배포
      - 최소: 4C / 8G / 100G
      - 권장: 8C / 16G / 500G
    - Standard Deployment
      - 최소: 4 VMs
      - VM resource 권장:
        - App: 8C / 32G / 100G
        - Database: 4C / 8G / 500G
        - Witness: 2C / 4G / 40G
    - High Availability Deployment
      - 최소: 6 VMs
      - VM resource 권장:
        - App (Swarm): 8C / 32G / 100G x 3
        - Database: 4C / 8G / 500G x 2
        - Witness: 2C / 4G / 40G

    :::tip[구체적인 requirements는 deployment scenario에 따라 달라질 수 있습니다]
    Enterprise hardware requirements는 deployment scenario에 따라 달라질 수 있습니다.
    :::

    :::note
    자세한 배포 정보는 [표준 배포 계획](../../reference/standard-deployment-plan/)과 [고가용성 배포 계획](../../reference/high-availability-deployment-plan/)을 확인하세요.
    :::

    #### 설치
    <Steps>
    1. package를 control host에 복사하고 검증합니다.
        ```bash
        sha256sum -c tier0-enterprise-offline-standard-YYYYmmddTHHMMSS.tar.gz.sha256
        ```
    2. package를 압축 해제합니다.
        ```bash
        tar -xzf tier0-enterprise-offline-standard-YYYYmmddTHHMMSS.tar.gz
        cd tier0-enterprise-offline-standard-YYYYmmddTHHMMSS
        ```
    3. deployment detail에 맞게 `install.env`를 수정한 뒤 deployment를 시작합니다.
        ```bash
        vi install.env
        bash install.sh
        ```
    </Steps>

    #### 유용한 운영 command
    - Enterprise 설치 전 deployment configuration을 점검합니다.
        ```bash
        ./install.sh --check-only
        ```
    - 실패한 deployment 후 모든 node를 정리합니다.
        ```bash
        ./full-cleanup.sh --env install.env --yes
        ```
        :::caution[영향 범위]
        이 명령은 VM, 운영체제, 설치 패키지, Docker 소프트웨어는 유지하지만 Tier0 런타임 데이터와 데이터베이스 백업을 삭제합니다.
        :::
    - 설치 후 deployment report가 생성됩니다.
        ```text
        runtime/install-reports/<timestamp>/deployment-report.md
        ```
        :::caution[보고서에 **FAIL** 항목이 있을 때]
        보고서에 **FAIL** 항목이 있으면 프로젝트를 인도하지 말고 먼저 지원팀에 문의하세요.
        :::

    #### 유지보수 참고 자료

    - [유지보수 및 문제 해결 가이드](../../reference/operations-runbook/)
    - [HA 경계 안내](../../reference/sla-and-ha-boundaries/)

  </TabItem>
  <TabItem label="Edge">

#### 요구사항
    - 최소 2코어 CPU, 2 GB RAM, 5 GB 디스크
    - 운영체제:
      - Windows: Windows 11 이상(64비트)
      - macOS: macOS 13 이상
      - Linux: Ubuntu 24.04 이상(64비트)

#### 설치
    <Steps>
	1. Tier0 Cloud에서 **UNS** > **연결** > **Edge**를 선택합니다.
	2. 운영체제에 맞는 Edge를 다운로드합니다.
	3. Tier0 Edge를 설치하고 Cloud에서 승인한 다음 연결을 완료합니다.
	</Steps>

  </TabItem>
