## 프로세스 이해

<Steps>
1. Tier0에서 **UNS**로 이동해 ERP에서 온 주문의 세부 정보를 확인합니다.
    - `DemoFactory/ERP/ProductionOrders/State/UpsertProductionOrder`: 주문.
    - `DemoFactory/ERP/ProductionOrders/State/OrderList`: 현재 주문 목록 스냅샷.
    :::tip[데이터는 어떻게 UNS로 수집되나요?]
    **Flows** > **Source Flow** > **DemoFactory-Flow**로 이동해 데이터 수집 세부 정보를 확인합니다.
    :::
2. (선택 사항) **Launchpad**로 이동해 **Work Order Management** 애플리케이션을 열고 **Production Orders** 페이지에서 주문을 생성합니다.
3. **Work Order Management**에서 **Plans** 페이지를 사용해 주문을 분할하고, 분할된 작업 주문의 생산 계획을 예약합니다.
4. 계획을 생산 부서로 보내고 **UNS**의 다음 topics에서 계획 세부 정보를 확인합니다.
    - `DemoFactory/ERP/WorkOrderPlan/Metric/SplitCount`: 분할 후 작업 주문 수.
    - `DemoFactory/ERP/WorkOrderPlan/State/PlanStatus`: 현재 계획 상태.
    - `DemoFactory/ERP/WorkOrderPlan/State/WorkOrderList`: 생산 계획 일정 이후의 작업 주문 목록.

    :::note
    애플리케이션은 plans와 workorders를 **UNS**에 직접 다시 씁니다.
    :::
5. 애플리케이션의 **Plan Details** 페이지에서 생산 진행 데이터를 확인합니다.
    :::tip[상세 데이터는 어디에서 오나요?]
    생산 진행 데이터는 생산 부서에서 오며, **Source Flow**의 **DemoFactory-Flow**가 이를 수집해 **UNS**에 게시하고 **Plan Details** 페이지에 표시합니다.
    - `DemoFactory/Site_01/Production/Line_01/WorkOrderExecution/State/CurrentWorkOrder`: 진행 중인 주문.
    - `DemoFactory/Site_01/Production/Line_01/WorkOrderExecution/State/WorkOrderStatus`: 현재 주문의 실행 상태.
    - `DemoFactory/Site_01/Production/Line_01/WorkOrderExecution/Metric/Target_Qty`: 현재 주문의 목표 생산량.
    - `DemoFactory/Site_01/Production/Line_01/WorkOrderExecution/Metric/Produced_Qty`: 현재 주문에서 완료된 제품 수량.
    - `DemoFactory/Site_01/Production/Line_01/WorkOrderExecution/Metric/Defect_Qty`: 현재 주문의 불량 수량.
    - `DemoFactory/Site_01/Production/Line_01/WorkOrderExecution/Metric/Completion_Rate`: 현재 주문의 완료율.
    :::
</Steps>
