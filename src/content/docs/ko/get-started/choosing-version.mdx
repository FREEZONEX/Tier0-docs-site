## Edge 하드웨어 요구사항

:::tip[Edge를 사용하려면]
Edge는 기술 평가 목적에 적합하며 운영 경험이 필요합니다. 사용 전에 환경이 아래 hardware requirements를 만족하는지 확인하세요.
:::

| | Minimum | Recommended |
|---|---|---|
| CPU | 4 cores | 8 cores |
| Memory | 8 GB | 16 GB |
| Disk | 100 GB (1000 IOPS) | 1 TB |
| OS | Ubuntu 24.04, Windows 10/11 (Docker) | - |

## "edge" 단위란?

Cloud plans에서 *edge*는 장비 가까이에서 데이터를 수집하고 namespace로 publish하는 connection point입니다. 일반적으로 collection flows를 실행하는 gateway 또는 industrial PC입니다. 대략 site 또는 독립 network segment마다 하나로 계산합니다. 위의 open-source distribution인 **Edge edition**과 혼동하지 마세요.
