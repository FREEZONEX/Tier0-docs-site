MQTT와 API를 통해 UNS 데이터를 조작할 수 있습니다.

## MQTT
Tier0에서 생성한 자격 증명으로 MQTT 클라이언트를 UNS broker에 연결할 수 있습니다.
:::note
**MQTTX**, **MQTT Explorer**, **Node-RED** 등의 클라이언트로 broker에 연결해 메시지를 게시하고 구독할 수 있습니다.
:::
### MQTT 자격 증명 생성
**Connect** > **Source** > **MQTT Device**에서 MQTT 자격 증명을 생성하고 기록합니다.
:::note[Tier0 Edge 예외]
Tier0 Edge의 외부 연결에는 자격 증명이 필요하지 않습니다.
:::
### MQTT 클라이언트 연결

:::tip
- UNS broker에는 다음 TCP 및 WSS 주소로 연결할 수 있습니다.
    - mqtt://host:1883
    - mqtts://host:8883
    - ws://host:8083/mqtt
    - wss://host:8084/mqtt
- 아래 연결 예시는 TLS가 없는 TCP를 사용합니다.
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a>를 설치하고 실행합니다.
2. UNS broker 정보와 생성한 자격 증명으로 연결을 추가합니다.
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```

  </TabItem>
  <TabItem label="MQTT Explorer">

1. <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a>를 설치하고 실행합니다.
2. UNS broker 정보와 생성한 자격 증명으로 새 연결을 추가합니다.
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```
3. 연결하기 전에 **ADVANCED**에서 Client ID를 자격 증명 ID로 변경합니다.

  </TabItem>
  <TabItem label="Node-RED">
- **Event Flow** 사용: Tier0의 Node-RED 기반 데이터 처리 모듈.

1. **Flows**에서 **Event Flow**를 만들고 `mqtt in` 노드로 시작합니다.
2. 노드의 **Server**로 UNS broker(Flow와 이름이 같음)를 선택하고 **Topic**을 UNS 모델로 설정합니다.

- **독립 Node-RED 인스턴스** 사용

1. <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> 인스턴스를 설치하고 실행합니다.
2. `mqtt in` 노드에 다음 정보로 서버를 추가합니다.
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 1883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### 연결 테스트
<Steps>
1. 클라이언트 상태가 정상인지 확인합니다.
2. UNS 모델 Topic을 복사하고 클라이언트에서 메시지를 게시합니다.
</Steps>

## API

### 기본 정보

- **Base URL**: `https://<your-tier0-host>/openapi/v2`
- **Authentication**: Tier0에서 발급받은 API 키를 `x-api-key` 헤더에 넣습니다.

### 요청 예시

- `POST /uns/metadata:find` — Collections 목록과 Collection ID 가져오기
  :::note
  `data.items`에서 원하는 Collection을 찾아 `id`를 복사합니다. 첫 페이지에 없으면 `data.pageInfo`를 확인하고 다음 페이지를 요청합니다.
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const response = await fetch(`${base}/uns/metadata:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data.items);
  ```

    </TabItem>
    <TabItem label="Python">

  ```python
  import requests

  response = requests.post(
      "https://your-tier0-host/openapi/v2/uns/metadata:find",
      headers={"x-api-key": "your-api-key"},
      json={"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}},
      timeout=30,
  )
  response.raise_for_status()
  result = response.json()
  if result["code"] != 0:
      raise RuntimeError(result.get("error", result.get("msg")))
  print(result["data"]["items"])
  ```

    </TabItem>
    <TabItem label="cURL">

  ```bash
  curl --fail-with-body -X POST "https://your-tier0-host/openapi/v2/uns/metadata:find" \
    -H "content-type: application/json" \
    -H "x-api-key: your-api-key" \
    -d '{"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}'
  ```

    </TabItem>
  </Tabs>

- `POST /uns/collections/{collectionId}/records:find` — Records 목록과 Record ID 가져오기
  :::note
  - `your-collection-id`를 `metadata:find`에서 얻은 ID로 바꿉니다.
  - `data.items`에서 대상 Record를 찾아 `id`를 복사합니다. 첫 페이지에 없고 `data.pageInfo.nextCursor`가 있으면 다음 요청의 `cursor`로 사용합니다.
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/records:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data);
  ```

    </TabItem>
    <TabItem label="Python">

  ```python

  response = requests.post(
      "https://your-tier0-host/openapi/v2/uns/collections/your-collection-id/records:find",
      headers={"x-api-key": "your-api-key"},
      json={"limit": 20},
      timeout=30,
  )
  response.raise_for_status()
  result = response.json()
  if result["code"] != 0:
      raise RuntimeError(result.get("error", result.get("msg")))
  ```

    </TabItem>

- `POST /uns/collections/{collectionId}/samples:find` — 기간 내 Samples 가져오기
  :::note
  - `your-collection-id`를 `metadata:find`에서 얻은 ID로 바꿉니다.
  - `recordIds`의 `record_123`을 `records:find`에서 얻은 Record ID로 바꿉니다.
  - `from`과 `to`를 원하는 시간 범위로 설정합니다.
  - 이 예시는 `temperature`로도 필터링합니다. 범위 내 모든 Samples가 필요하거나 Collection에서 다른 필드를 사용하면 이 필터를 제거합니다.
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/samples:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"recordIds": ["record_123"], "from": 1792454400000, "to": 1792540800000, "filter": {"temperature": {"$gt": 20}}, "limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data);
  ```

    </TabItem>
    <TabItem label="Python">
