MQTT와 API를 통해 UNS 데이터를 조작할 수 있습니다.

## MQTT
MQTT client는 Tier0에서 생성한 credential로 UNS broker에 연결할 수 있습니다.
:::note
**MQTTX**, **MQTT Explorer**, **Node-RED** 같은 MQTT client를 사용해 broker에 연결하고 message를 publish/subscribe할 수 있습니다.
:::
### MQTT Credential 생성
Tier0의 **Edge** 탭에서 새 credential을 만들고 기록해 둡니다.
:::note[Tier0 Edge version 예외]
Tier0 Edge version은 외부 연결에 credential이 필요하지 않습니다.
:::
### MQTT Client 연결

:::tip
- UNS broker는 다음 주소로 TCP와 WSS를 모두 지원합니다.
    - mqtt://host:1883
    - mqtts://host:8883
    - ws://host:8083/mqtt
    - wss://host:8084/mqtt
- 아래 연결 예시는 TLS 없는 TCP를 기준으로 합니다.
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a>를 설치하고 엽니다.
2. Tier0 UNS broker 정보와 생성된 credential로 connection을 추가합니다.
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```

  </TabItem>
  <TabItem label="MQTT Explorer">

1. <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a>를 설치하고 엽니다.
2. broker 정보와 생성된 credential로 새 connection을 추가합니다.
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```
3. 연결하기 전에 **ADVANCED**에서 client ID를 credential ID로 변경합니다.

  </TabItem>
  <TabItem label="Node-RED">
      - **Event Flow** 사용 - Tier0 안의 Node-RED 기반 data processing module입니다.
          1. **Event Flow**에서 flow를 만들고 `mqtt in` node로 시작합니다.
          2. node에서 **Server**를 UNS broker(flow와 같은 이름)로 선택하고 **Topic**을 UNS model로 설정합니다.
      - **독립 Node-RED Instance** 사용
          1. <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> instance를 설치하고 엽니다.
          2. `mqtt in` node에서 아래 정보로 server를 추가합니다.
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 1883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### Connection 테스트
<Steps>
1. client status가 정상인지 확인합니다.
2. UNS model topic을 복사하고 client를 통해 message를 publish합니다.
</Steps>

## API

### Cloud v2 데이터 조회

Cloud v2는 `https://<your-cloud-host>/openapi/v2`와 `x-api-key`를 사용합니다. 다음 예시는 업무 레코드와 실제 시계열 샘플을 조회합니다. Edge 또는 Enterprise에는 적용되지 않습니다.

먼저 `POST /uns/metadata:find`에 `{"kind":"collection","filter":{},"page":{"mode":"offset","page":1,"size":20}}`를 보냅니다. 선택한 컬렉션의 `data.items[].id`가 `collectionId`입니다. `records:find`가 반환한 레코드의 `id`를 샘플 조회의 `recordId`로 사용합니다. 두 ID 모두 UNS 경로가 아닙니다.

#### 업무 레코드 조회: `records:find`

<Tabs syncKey="uns-api-language">
  <TabItem label="JavaScript">

```js
const base = process.env.TIER0_BASE_URL; // https://<your-cloud-host>/openapi/v2
const collectionId = process.env.TIER0_COLLECTION_ID;
const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/records:find`, {
  method: "POST",
  headers: { "content-type": "application/json", "x-api-key": process.env.TIER0_API_KEY },
  body: JSON.stringify({"filter": {"status": "running"}, "limit": 20}),
});
const result = await response.json();
if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
console.log(result.data);
```

  </TabItem>
  <TabItem label="Python">

```python
import os
import requests

response = requests.post(
    f"{os.environ['TIER0_BASE_URL']}/uns/collections/{os.environ['TIER0_COLLECTION_ID']}/records:find",
    headers={"x-api-key": os.environ["TIER0_API_KEY"]},
    json={"filter": {"status": "running"}, "limit": 20},
    timeout=30,
)
response.raise_for_status()
result = response.json()
if result["code"] != 0:
    raise RuntimeError(result.get("error", result.get("msg")))
print(result["data"])
```

  </TabItem>
  <TabItem label="cURL">

```bash
curl --fail-with-body -X POST "$TIER0_BASE_URL/uns/collections/${TIER0_COLLECTION_ID}/records:find" \
  -H "content-type: application/json" \
  -H "x-api-key: $TIER0_API_KEY" \
  -d '{"filter": {"status": "running"}, "limit": 20}'
```

  </TabItem>
</Tabs>

#### 과거 샘플 조회: `samples:find`

<Tabs syncKey="uns-api-language">
  <TabItem label="JavaScript">

```js
const base = process.env.TIER0_BASE_URL; // https://<your-cloud-host>/openapi/v2
const collectionId = process.env.TIER0_COLLECTION_ID;
const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/samples:find`, {
  method: "POST",
```

  </TabItem>

`samples:latest`는 요청한 각 레코드의 `{recordId, sample}`을 `data.series`에 반환합니다. 샘플이 없으면 `sample`은 `null`입니다. `samples:find`는 `data.items`와 `data.pageInfo`를 반환합니다. `from`과 `to`는 Unix 밀리초이며 범위는 `[from, to)`입니다. `temperature` 같은 필터는 업무 필드를 직접 가리키고 반환값은 각 샘플의 `data`에 있습니다.
