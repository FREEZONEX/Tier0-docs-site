MCP를 통해 AI Agent를 Tier0에 연결합니다. Agent는 부여된 권한 범위에서 플랫폼 API를 찾아 사용할 수 있습니다.

<AgentIcons />

:::note[시작하기 전에]
- **Settings** > **MCP Access**에서 MCP URL을 가져옵니다.
- Agent 클라이언트가 HTTP를 통한 원격 MCP를 지원해야 합니다.
:::

## Agent 연결하기

Codex를 예로 사용합니다.

<Tabs syncKey="edition">
  <TabItem label="수동 추가">
    1. **Settings** > **Plugin** > **MCP**에서 Tier0의 URL로 MCP 서버를 추가합니다.
    2. Tier0의 **Settings** > **API Keys** > **Personal Keys**에서 필요한 권한의 개인 API 키를 만듭니다.
    3. Codex의 MCP 서버에 개인 API 키를 입력합니다.
       ```json
       { "Authorization": "Bearer <your-personal-api-key>" }
       ```
    4. Agent에게 `whoami`를 실행하여 연결을 확인하도록 요청합니다.
  </TabItem>
  <TabItem label="명령줄">
    1. PowerShell에서 다음 명령을 실행하고 브라우저에서 로그인합니다.
       ```bash
       codex mcp add tier0 --url https://your-tier0-url/mcp --oauth-client-registration dcr
       ```
    2. 브라우저에서 Workspace를 승인하고 해당 권한을 부여합니다.
       ```bash
       codex mcp login tier0 --oauth-client-registration dcr
       ```
    3. Agent에게 `whoami`를 실행하여 연결을 확인하도록 요청합니다.
  </TabItem>
</Tabs>

## Agent로 Tier0 운영하기

| MCP 도구 | 용도 |
| --- | --- |
| `whoami` | 신원과 권한을 확인합니다. |
| `docs` | API 문서를 읽습니다. |
| `search` | API 작업을 찾습니다. |
| `execute` | API 작업을 호출합니다. |

먼저 Agent에게 `docs`와 `search`로 작업을 찾고 `execute`로 호출하도록 요청합니다. 예:

```text
내 Workspace의 `Plant/Line1/Metric/Temperature` 현재 값을 읽어 줘.
```

:::tip[결과가 없을 때]
쓰기 후 Agent에게 결과를 다시 읽도록 요청합니다. `outcome=unknown`이면 재시도하기 전에 현재 상태를 확인합니다.
:::
