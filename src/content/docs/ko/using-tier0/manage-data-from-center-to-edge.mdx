Tier0의 엣지-센터 협업을 통해 엣지 디바이스에서 데이터를 수집하고 중앙 플랫폼에서 관리할 수 있습니다.
- 엣지 디바이스: 엣지 노드의 Tier0 Edge 또는 Tier0 Enterprise.
- 중앙 플랫폼: 중앙 노드의 Tier0 Cloud 또는 Tier0 Enterprise.

## 엣지 노드를 중앙 노드에 연결하기

<Tabs syncKey="edition">
  <TabItem label="Enterprise">
    <Steps>
    1. 먼저 중앙 노드에서 Fleet 노드를 생성합니다.

            :::note
            연결할 수 있는 엣지 노드 수는 라이선스에 따라 달라집니다.
            :::
    2. 중앙 노드에서 생성된 토큰을 사용하여 각 엣지 노드를 연결합니다.
    </Steps>
  </TabItem>
  <TabItem label="Cloud">
    <Steps>
    1. 운영체제에 맞는 Tier0 Edge를 Tier0 Cloud에서 다운로드합니다.
    2. 인증을 완료하고 엣지와 클라우드를 연결합니다.
    </Steps>
  </TabItem>
</Tabs>

## 엣지와 센터 간 데이터 동기화

<Tabs syncKey="edition">
  <TabItem label="Enterprise">
    - Namespace Table은 엣지 노드에서 중앙 노드로만 선택하여 동기화할 수 있습니다. 동기화한 Table의 과거 데이터와 실시간 데이터를 모두 중앙 노드에서 사용할 수 있습니다.
    - 중앙 노드에서 엣지 노드에 사용자 또는 사용자 그룹을 할당하여 노드를 관리할 수 있습니다.

    :::note
    그룹 사용자가 엣지 노드에서 허용된 앱에 접근할 수 있도록 먼저 중앙 노드에서 사용자 그룹의 앱 접근 권한을 설정하세요.
    :::
  </TabItem>
  <TabItem label="Cloud">
    - 연결이 완료되면 Namespace Table의 스키마는 기본적으로 엣지에서 클라우드로 동기화됩니다.
    - 선택한 Table의 레코드만 클라우드로 동기화됩니다.
    - 중앙 플랫폼에서 엣지 노드에 사용자 또는 사용자 그룹을 할당하여 노드를 관리할 수 있습니다.

    :::tip[엣지에 독립적인 Agent 없이 데이터 연결하기]
    연결한 후 클라우드의 Agent에게 데이터 소스를 연결하고 데이터 스트림을 구축하도록 요청하여 엣지에서 데이터를 가져오고 처리할 수 있습니다.
    :::
  </TabItem>
</Tabs>
