AI와 대화하여 맞춤형 산업용 앱을 만듭니다. 앱은 공장 데이터를 사용하며 역할 기반 접근 제어, 버전 관리, 외부 배포 기능을 제공합니다.

## Tier0 앱 만들기

- 폴더는 앱 분류에만 사용됩니다.
- 프롬프트에 따라 템플릿이 자동으로 선택되어 개발 시간을 절약합니다.
- 설비 관리, 생산 모니터링, 에너지 관리 등 일반 산업용 앱을 위한 템플릿 프롬프트가 있습니다.

### 프롬프트 작성

앱의 목적, 기능, 외부 데이터 필요 여부를 설명합니다. 예:

```text
공장 기술자를 위한 설비 유지보수 앱을 만들어 설비 상태 확인, 요청 제출, 수리 진행 상황 추적을 지원해 줘.
xxx collection의 경보 기록과 유지보수 이력을 사용해 줘.
```

:::note
- 앱 시작에 필요한 모의 데이터는 **Namespace**에서 생성하고 모델링합니다.
- 외부 데이터는 Agent가 연결하고 **Namespace**에서 모델링해야 합니다.
:::

:::tip[앱을 더 빠르게 만들기]
- **Library**의 산업용 앱 템플릿을 사용한 뒤 기능을 수정합니다.
- [내장 Builder Skills](../../reference/embedded-builder-skills/)를 사용합니다.
- 대화가 길어지면 `/clear`로 컨텍스트를 지우거나 `/compact`로 압축합니다.
:::

### 접근 제어

앱은 역할 기반 접근 제어(RBAC)로 멤버의 접근과 허용 작업을 관리합니다.

- 별도 지정이 없으면 Agent가 비즈니스 로직에 따라 역할을 생성합니다. 책임이 맞는 기존 역할을 재사용할 수도 있습니다.
- 앱 역할은 Workspace 멤버에게만 할당할 수 있습니다.
- 프롬프트에 역할이 필요 없다고 명시하면 모든 멤버가 앱을 사용할 수 있습니다.

:::tip[역할 직접 지정]
프롬프트에 역할과 권한 범위를 적습니다. Agent가 다른 앱의 기존 역할과 비교하고 충돌 시 확인합니다.
:::

:::caution[역할 제어 앱에는 앱 역할 할당이 필수]
**Launchpad**에서 접근하려면 앱 역할이 있어야 합니다. Workspace 소유자도 앱 역할이 없으면 접근할 수 없습니다.
:::

### 버전 관리

- **미게시**: 앱의 최신 상태. 배포 전 변경 사항은 다른 버전에 영향을 주지 않습니다.
- **스냅샷**: 저장 당시 상태. 배포하면 현재 온라인 버전을 대체합니다.
- **게시됨**: 현재 온라인 버전.

미게시 버전을 배포하면 온라인 앱이 업데이트되고, 스냅샷을 배포하면 이전 버전으로 돌아갑니다. 스냅샷은 앱 미리보기 페이지에 표시됩니다.

### 외부로 내보내기

앱이 준비되면 **Preview** 페이지에서 타사 환경이나 Tier0 Enterprise용으로 내보낼 수 있습니다.

- **소스 코드 다운로드**: 추가 개발용.
- **Bundle 내보내기**: **Tier0 Enterprise**에서 로컬로 가져오기 위한 용도.

스냅샷 버전의 소스 코드가 필요하면 스냅샷을 저장한 뒤 다운로드합니다.
