Tier0는 Marimo Notebook을 사용해 **Python** 스크립트로 고급 데이터 분석을 수행합니다.

:::tip[시작 전 확인]
**Enable History**가 켜진 UNS 데이터만 **Notebook**에서 사용 가능한 데이터 소스로 표시됩니다.
:::

<Steps>
1. UNS 데이터에서 **VARIABLES** > **PostgreSQL** > **tenant_id** > **uns**를 선택합니다.
2. **GENERATE WITH AI**를 클릭한 뒤 **@**로 분석할 변수를 선택합니다. Notebook은 변수 검색을 돕기 위해 fuzzy match를 지원합니다.
3. 필요에 따라 분석을 계속하거나 생성 결과를 롤백합니다.
</Steps>

:::tip[Notebook의 AI 지원]
- Tier0 Cloud에서는 AI 지원을 바로 사용할 수 있습니다.
- Tier0 Enterprise에서는 자체 AI key를 설정해야 합니다.
:::
