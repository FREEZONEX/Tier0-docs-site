Tier0에 연결된 공장 데이터는 실제와 유사한 동작과 환경을 갖춘 Digital Twin으로 시각화할 수 있습니다. 전체 과정은 데이터를 3D 모델에 매핑한 뒤 여러 모델을 조합해 완전한 공장 장면을 만드는 흐름입니다.

## 데이터를 3D 모델에 매핑하기
<Steps>
1. **Model**에 모델을 업로드한 뒤, UNS 데이터로 실시간 동작을 제어할 노드를 선택합니다.
2. 같은 모델에 서로 다른 UNS 데이터를 가진 인스턴스를 추가해 여러 설비를 시뮬레이션합니다.
3. 데이터를 모델에 바인딩하고 **Preview**를 사용해 데이터 변화에 따라 모델이 이동하고 회전하는지 확인합니다.
    - **Position**: 모델이 선택한 좌표 방향으로 이동합니다.
    - **Rotation**: 모델이 좌표 원점을 기준으로 회전합니다.
4. **Data Tagging**을 사용해 정적 정보 표시용 태그를 추가합니다.
</Steps>

## 데이터 시각화하기
<Steps>
1. **Instance Library**에서 장면에 있어야 하는 인스턴스를 추가합니다.
2. 상단 도구를 사용해 모델을 이동, 확대/축소, 회전하여 장면에 맞추고, 시점과 좌표 위치를 조정합니다.
3. 오른쪽의 **Object**에서 모델 위치를 확인할 수 있으며, 여기에 바인딩된 UNS 데이터가 표시됩니다.
4. 뷰포트와 조명은 환경 세부 설정에 사용합니다.
</Steps>

## 외부 공유
인스턴스만 모델 단위 또는 장면 단위로 공유할 수 있습니다.
- **Share Model**: 실시간 UNS 데이터가 표시되는 모델의 Tier0 플랫폼 링크를 생성합니다.
- **Share Scene**: 실시간 UNS 데이터와 환경 설정이 포함된 모델 및 장면의 Tier0 플랫폼 링크를 생성합니다.
