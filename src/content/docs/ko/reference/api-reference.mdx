## 연결 및 인증

- **기본 URL**: `https://<your-tier0-host>/openapi/v2`
- **인증**: `x-api-key` 요청 헤더에 Tier0 API 키를 보냅니다.

## 결과 확인

- `/uns/` 요청은 HTTP 상태와 응답 본문을 모두 확인합니다. 성공 응답은 `2xx` 상태와 `code: 0`이며 결과는 `data`에 있습니다.
- 실패하면 `error.code`를 확인하고 문제 해결을 위해 `requestId`를 보관합니다.
- 일괄 요청은 HTTP `200`이어도 각 항목을 확인합니다. 일부 항목은 실패했을 수 있습니다.

## 쓰기 재시도

- `error.execution`으로 쓰기가 시작되지 않았는지, 롤백됐는지, 커밋됐는지, 결과를 알 수 없는지 확인합니다.
- `error.retry.safe`가 `true`일 때만 동일한 멱등성 키로 같은 요청을 재시도합니다. 대기 시간이 지정되면 `error.retry.afterMs` 또는 `Retry-After` 헤더에 표시된 시간 이상 기다립니다.
- 일괄 요청의 일부가 커밋됐다면 성공 항목을 확인한 뒤 나머지를 전송합니다. 결과를 알 수 없고 안전한 재시도가 확인되지 않았다면 다시 보내기 전에 쓰기가 적용됐는지 확인합니다.
