ISA-95 설비 계층은 조직 내 물리 자산과 제어 시스템이 어떻게 구조화되는지 설명합니다.

다음 계층으로 나뉩니다.

- **Enterprise**: 조직 전체를 나타내는 최상위 계층입니다. 전체 비즈니스 프로세스와 의사결정 주체를 포함하며, 일반적으로 ERP 시스템의 지원을 받습니다.
- **Site**: 특정 지리적 위치나 시설을 나타냅니다. 각 site는 자체 관리 시스템과 로컬 생산 제어를 가질 수 있습니다.
- **Area**: site 내의 운영 구역으로, 포장, 조립, 창고와 같은 기능 영역인 경우가 많습니다.
- **Process Cell**: area 내 제조의 기본 단위입니다. 특정 제품을 생산하거나 특정 기능을 수행하는 데 필요한 모든 설비를 포함합니다.
- **Unit**: process cell의 독립적인 부분으로, 혼합, 가열, 조립 같은 특정 기능을 담당합니다.
- **Equipment Module**: unit 내에서 특정 작업을 수행하는 모듈형 설비입니다. 예를 들어 혼합 unit에서는 가열 요소가 equipment module이 될 수 있습니다.
- **Control Module**: 최하위 계층으로, 센서, 펌프, 액추에이터, PID 제어 루프처럼 물리 프로세스를 직접 제어하는 개별 장치나 컨트롤러를 나타냅니다.
