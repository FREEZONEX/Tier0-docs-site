## 接続と認証

- **ベース URL**: `https://<your-tier0-host>/openapi/v2`
- **認証**: `x-api-key` リクエストヘッダーに Tier0 API キーを指定します。

## 結果の確認

- `/uns/` リクエストでは HTTP ステータスと応答本文の両方を確認します。成功時は `2xx` かつ `code: 0` で、結果は `data` にあります。
- 失敗時は `error.code` を確認し、調査用に `requestId` を保存します。
- バッチでは HTTP `200` でも各項目を確認します。一部の項目だけ失敗する場合があります。

## 書き込みの再試行

- `error.execution` を確認し、未開始、ロールバック済み、コミット済み、結果不明のいずれかを判断します。
- `error.retry.safe` が `true` の場合に限り、同じ冪等キーで同一リクエストを再試行します。待機時間が示された場合は、`error.retry.afterMs` または `Retry-After` ヘッダー以上待ちます。
- バッチの一部がコミットされた場合、成功項目を確認してから残りを送信します。結果不明で安全な再試行が確認できない場合は、再送前に書き込みの反映を確認します。

## 用語

- **冪等性**: 操作を繰り返しても一度だけ行った場合と同じ結果になることです。対応する書き込みでは、同じリクエストの再試行に同じキーを使い、別の書き込みには新しいキーを使います。
