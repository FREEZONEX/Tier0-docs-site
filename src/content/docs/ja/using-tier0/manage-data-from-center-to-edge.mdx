Tier0 のエッジとセンターの連携により、エッジデバイスでデータを収集し、センタープラットフォームで管理できます。
- エッジデバイス：エッジノード上の Tier0 Edge または Tier0 Enterprise。
- センタープラットフォーム：センターノード上の Tier0 Cloud または Tier0 Enterprise。

## エッジノードをセンターノードに接続する

<Tabs syncKey="edition">
  <TabItem label="Enterprise">
    <Steps>
    1. まず、センターノードで Fleet ノードを作成します。

            :::note
            接続できるエッジノードの数はライセンスによって異なります。
            :::
    2. センターノードで生成されたトークンを使用して、各エッジノードを接続します。
    </Steps>
  </TabItem>
  <TabItem label="Cloud">
    <Steps>
    1. オペレーティングシステムに応じて、Tier0 Cloud から Tier0 Edge をダウンロードします。
    2. 認証を完了し、エッジとクラウドを接続します。
    </Steps>
  </TabItem>
</Tabs>

## エッジとセンターの間でデータを同期する

<Tabs syncKey="edition">
  <TabItem label="Enterprise">
    - Namespace Collection はエッジノードからセンターノードへ一方向にのみ選択・同期できます。同期した Collection の履歴データとリアルタイムデータは、どちらもセンターノードで利用できます。
    - センターノードからエッジノードにユーザーまたはユーザーグループを割り当て、ノードを管理できます。

    :::note
    グループ内のユーザーがエッジノードの許可されたアプリにアクセスできるよう、先にセンターノードでユーザーグループにアプリのアクセス権を設定してください。
    :::
  </TabItem>
  <TabItem label="Cloud">
    - 接続後、Namespace Collection のスキーマはデフォルトでエッジからクラウドに同期されます。
    - レコードがクラウドに同期されるのは、選択した Collection のみです。
    - センタープラットフォームからエッジノードにユーザーまたはユーザーグループを割り当て、ノードを管理できます。

    :::tip[エッジに独立した Agent を配置せずにデータを接続する]
    接続後は、クラウド上の Agent にデータソースの接続とデータストリームの構築を依頼し、エッジ上でデータを取得・処理できます。
    :::
  </TabItem>
</Tabs>
