Tier0 は Marimo Notebook を使い、**Python** スクリプトで高度なデータ分析を行います。

:::tip[始める前に]
**Enable History** が有効な UNS データだけが、**Notebook** で利用できるデータソースとして表示されます。
:::

<Steps>
1. UNS データで **VARIABLES** > **PostgreSQL** > **tenant_id** > **uns** を選択します。
2. **GENERATE WITH AI** をクリックし、**@** を使って分析対象の変数を選択します。Notebook は変数検索のために fuzzy match をサポートします。
3. 必要に応じて分析を続けるか、生成結果をロールバックします。
</Steps>

:::tip[Notebook の AI 支援]
- Tier0 Cloud では AI 支援を直接利用できます。
- Tier0 Enterprise では独自の AI key を設定する必要があります。
:::
