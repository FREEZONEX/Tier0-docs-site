MCP を介して AI Agent を Tier0 に接続します。Agent は付与された権限の範囲でプラットフォーム API を検索して使用できます。

<AgentIcons />

:::note[始める前に]
- **設定** > **MCP Access** から MCP URL を取得します。
- Agent クライアントは HTTP 経由のリモート MCP に対応している必要があります。
:::

## Agent を接続する

以下では Codex を例にします。

<Tabs syncKey="edition">
  <TabItem label="手動で追加">
    1. **設定** > **Plugin** > **MCP** で Tier0 から取得した URL を使って MCP サーバーを追加します。
    2. Tier0 の **設定** > **API Keys** > **Personal Keys** で必要な権限の個人 API キーを作成します。
    3. Codex の MCP サーバーに個人 API キーを入力します。
       ```json
       { "Authorization": "Bearer <your-personal-api-key>" }
       ```
    4. Agent に `whoami` を実行させ、接続を確認します。
  </TabItem>
  <TabItem label="コマンドライン">
    1. PowerShell で次を実行し、ブラウザーでログインします。
       ```bash
       codex mcp add tier0 --url https://your-tier0-url/mcp --oauth-client-registration dcr
       ```
    2. ブラウザーで Workspace を認可し、必要な権限を付与します。
       ```bash
       codex mcp login tier0 --oauth-client-registration dcr
       ```
    3. Agent に `whoami` を実行させ、接続を確認します。
  </TabItem>
</Tabs>

## Agent で Tier0 を操作する

| MCP ツール | 用途 |
| --- | --- |
| `whoami` | ID と権限を確認します。 |
| `docs` | API ドキュメントを読みます。 |
| `search` | API 操作を探します。 |
| `execute` | API 操作を呼び出します。 |

まず `docs` と `search` で操作を探し、次に `execute` で呼び出します。例：

```text
Workspace の `Plant/Line1/Metric/Temperature` の現在値を読み取ってください。
```

:::tip[結果が得られない場合]
書き込み後に Agent に結果を再読み取りさせます。`outcome=unknown` と表示された場合は、再試行する前に現在の状態を確認します。
:::
