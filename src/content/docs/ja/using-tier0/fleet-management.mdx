実際の工場では、ネットワーク帯域幅の使用量を抑え、データセキュリティを向上させるため、データをエッジデバイスで収集し、センターノードから一元管理することがよくあります。
Tier0 は、センターノードからエッジノード上のデータを管理する Fleet Management ソリューションを提供します。

## エッジノードをセンターノードに接続する

<Steps>
1. エッジノードから接続を確立する前に、センターノードで Fleet ノードを作成します。

        :::note
        Tier0 Cloud と Enterprise はどちらもセンターノードとして使用できますが、接続できるエッジノードの数はプランとライセンスによって異なります。
        :::
2. センターノードから取得したトークンを使用して、各エッジノードで接続を確立します。
</Steps>

## エッジとセンターの間でデータを同期する

- UNS データは、エッジノードからセンターノードへの方向にのみ選択して同期できます。
- センターノードからエッジノードにユーザーを割り当て、ノードを管理できます。
