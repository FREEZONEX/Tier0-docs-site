Tier0 では、MQTT と API を通じて UNS を操作できます。

## MQTT
Tier0 では、MQTT clients が credentials を使って UNS broker に接続できます。
:::note
**MQTTX**、**MQTT Explorer**、**Node-RED** などの MQTT clients を使って broker に接続し、messages を publish/subscribe できます。
:::
### MQTT Credentials を生成する
Tier0 の **Edge** ページで新しい credential を作成し、記録します。

### MQTT Clients を接続する

:::tip
以下の clients は、credentials を使って UNS broker に接続する方法を示す例です。
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a> をインストールして開きます。
2. UNS broker の情報と生成された credentials を使って connection を追加します。
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 

  </TabItem>
  <TabItem label="MQTT Explorer">

1. <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a> をインストールして開きます。
2. UNS broker の情報と生成された credentials を使って新しい connection を追加します。
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 
3. Change the client ID to the credential ID in **ADVANCED** before connecting.

  </TabItem>
  <TabItem label="Node-RED">
      - **Event Flow** を使用 - Tier0 内の Node-RED ベースのデータ処理モジュールです。
          1. **Flows** で **Event Flow** を作成し、`mqtt in` node から開始します。
          2. node 内で UNS broker を **Server**（flow と同じ名前）として選択し、**Topic** を UNS model に設定します。
      - **別の Node-RED Instance** を使用
          1. <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> instance をインストールして開きます。
          2. `mqtt in` node に、次の情報で server を追加します。
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 8883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### 接続をテストする
<Steps>
1. **Edge** ページで、**Clients** tab にある各 client の status が normal であることを確認します。
2. UNS model topic をコピーし、client からその topic に message を publish します。
3. **UNS** に戻り、対象 topic の下にあるデータを確認します。
</Steps>

## API
**REST API** を使用して UNS データを操作します。
:::tip[API の使い方]
- OpenAPI の base path は `/openapi/v1` です。`TIER0_BASE_URL` には Tier0 host と base path を合わせた値（例: `https://your-workspace.tier0.app/openapi/v1`）を設定し、API key は `x-api-key` header で渡します。
- API keys は右上のアカウントアイコンから **Settings > API Keys** に移動して生成できます。
:::

- `/uns/create`

  UNS path nodes または topic nodes を作成します。`namespace` で node tree を定義します。

  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

      ```js
      const BASE_URL = process.env.TIER0_BASE_URL;
      const API_KEY = process.env.TIER0_API_KEY;

      const response = await fetch(`${BASE_URL}/uns/create`, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          'x-api-key': API_KEY,
        },
        body: JSON.stringify({
          namespace: [
            {
              name: 'DemoFactory',
              type: 'PATH',
              children: [
                {
                  name: 'Site_01',
                  type: 'PATH',
                  children: [
                    {
                      name: 'Production',
                      type: 'PATH',
                      children: [
                        {
                          name: 'Produced_Qty',
                          type: 'TOPIC',
                          topicType: 'METRIC',
                          displayName: 'Produced Quantity',
                          description: 'Produced quantity from the production line.',
                          enableHistory: true,
                          fields: [
                            { name: 'value', type: 'DOUBLE', unit: 'pcs' },
                          ],
                        },
                      ],
                    },
                  ],
                },
              ],
            },
          ],
        }),
      });

      const result = await response.json();
      console.log(result.data.results);
      ```

    </TabItem>
    <TabItem label="Python">

      ```python
      import os
      import requests

      base_url = os.environ["TIER0_BASE_URL"]
      api_key = os.environ["TIER0_API_KEY"]

      response = requests.post(
          f"{base_url}/uns/create",
          headers={"x-api-key": api_key},
          json={
              "namespace": [
                  {
                      "name": "DemoFactory",
                      "type": "PATH",
                      "children": [
                          {
                              "name": "Site_01",
                              "type": "PATH",
                              "children": [
                                  {
                                      "name": "Production",
                                      "type": "PATH",
                                      "children": [
                                          {
                                              "name": "Produced_Qty",
                                              "type": "TOPIC",
                                              "topicType": "METRIC",
                                              "displayName": "Produced Quantity",
                                              "description": "Produced quantity from the production line.",
                                              "enableHistory": True,
                                              "fields": [
                                                  {"name": "value", "type": "DOUBLE", "unit": "pcs"},
                                              ],
                                          },
                                      ],
                                  },
                              ],
                          },
                      ],
                  },
              ],
          },
          timeout=30,
      )
      response.raise_for_status()

      result = response.json()
      print(result["data"]["results"])
      ```

    </TabItem>
    <TabItem label="cURL">

      ```bash
      curl -X POST "$TIER0_BASE_URL/uns/create" \
        -H "content-type: application/json" \
        -H "x-api-key: $TIER0_API_KEY" \
        -d '{
          "namespace": [
            {
              "name": "DemoFactory",
              "type": "PATH",
              "children": [
                {
                  "name": "Site_01",
                  "type": "PATH",
                  "children": [
                    {
                      "name": "Production",
                      "type": "PATH",

                          "enableHistory": true,

                          ]
                        }
                      ]
                    }
                  ]
                }
              ]
            }
          ]
        }'
      ```

- `/uns/read`

  1 つ以上の UNS topics の最新値とメタデータを読み取ります。

  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

      ```js
      const BASE_URL = process.env.TIER0_BASE_URL;
      const API_KEY = process.env.TIER0_API_KEY;

      const response = await fetch(`${BASE_URL}/uns/read`, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          'x-api-key': API_KEY,
        },
        body: JSON.stringify({
          topics: [
            'DemoFactory/Site_01/Production/Produced_Qty',
          ],
          include_leaf_value: true,
          include_metadata: true,
        }),
      });

      const result = await response.json();
      console.log(result.data.results);
      ```

    </TabItem>
    <TabItem label="Python">

- `/uns/update`

  `path` で UNS node を更新します。`updateMask` を使用して変更するフィールドを指定します。

  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

      ```js
      const BASE_URL = process.env.TIER0_BASE_URL;
      const API_KEY = process.env.TIER0_API_KEY;

      const response = await fetch(`${BASE_URL}/uns/update`, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          'x-api-key': API_KEY,
        },
        body: JSON.stringify({
          path: 'DemoFactory/Site_01/Production/Produced_Qty',
          displayName: 'Produced Quantity',
          description: 'Updated production output quantity.',
          updateMask: ['displayName', 'description'],
        }),
      });

      const result = await response.json();
      console.log(result.data);
      ```

    </TabItem>
    <TabItem label="Python">

      ```python
      import os
      import requests

      base_url = os.environ["TIER0_BASE_URL"]
      api_key = os.environ["TIER0_API_KEY"]

      response = requests.post(
          f"{base_url}/uns/update",
          headers={"x-api-key": api_key},
          json={
              "path": "DemoFactory/Site_01/Production/Produced_Qty",
              "displayName": "Produced Quantity",
              "description": "Updated production output quantity.",
              "updateMask": ["displayName", "description"],
          },
          timeout=30,

    </TabItem>

- `/uns/delete`

  1 つ以上の UNS models を削除します。`hard_delete: false` を使用すると models をごみ箱へ移動します。

  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

      const BASE_URL = process.env.TIER0_BASE_URL;

        method: 'POST',
        headers: {
          'content-type': 'application/json',
          'x-api-key': API_KEY,
        },
        body: JSON.stringify({
          topics: [
            'DemoFactory/Site_01/Production/Produced_Qty',
          ],
          hard_delete: false,
        }),
      });

      const result = await response.json();
      console.log(result.data);
      ```

    </TabItem>
    <TabItem label="Python">
