AI との対話を通じて、カスタム産業アプリケーションを構築します。アプリケーションは工場データを利用でき、ロールベースのアクセス制御、バージョン管理、デプロイなどの機能を備えています。

## Tier0 アプリを構築する
アプリケーションを構築する前に、project を作成します。

- Project はアプリケーションを分類し、アプリケーションのアクセス制御を管理するために使用します。
- 同じ project 内のアプリケーションは、複雑なシステムの関連する機能モジュールとして扱えます。
- 各 project のデータは、他の project から独立しています。

### Prompt を書く
Agent が要件に合ったアプリケーションを生成できるように、prompt には***少なくとも***次の内容を含めてください。

- **アプリケーションの目的**：このアプリケーションは何のためのものですか？
    ```text
    工場の技術者向けに、設備保全アプリケーションを作成してください。
    ```
- **アプリケーションデータ**：アプリケーションはどのデータを使用し、そのデータはどこにありますか？

    <Tabs>
    <TabItem label="Platform Plan">
    [UNS にデータを接続](../connect-data/)し、prompt で UNS topic を指定します。
    ```text
    このアプリケーションは、xxx UNS model の設備ステータス、アラーム記録、保全履歴を使用してください。
    ```
    </TabItem>
    <TabItem label="Builder Plan">
    Agent は初期化時に、起動用のデータを自動的にシミュレートします。
    </TabItem>
    </Tabs>
- **アプリケーション機能**：アプリケーションは何を行いますか？
    ```text
    このアプリケーションでは、ユーザーが設備状態を監視し、保全依頼を送信し、修理進捗を追跡できるようにしてください。
    ```

:::caution[**Builder** を使用している場合]
**Builder** plan は現在 UNS をサポートしていませんが、シミュレーションデータを利用できます。より具体的なデータ統合が必要な場合は、sales@freezonex.io までお問い合わせください。
:::
:::tip[より速くアプリケーションを構築する]
- 一般的な産業アプリケーションのテンプレートは **Library** に用意されています。テンプレートを利用し、その上で機能を変更すると、より速くアプリケーションを構築できます。
- [組み込み Builder Skills](../../reference/embedded-builder-skills/) を使ってアプリケーション構築を支援できます。
- 会話が長くなりすぎた場合は、`/clear` でコンテキストをクリアし、`/compact` でコンテキストを圧縮します。
:::

### アクセス制御
ロールベースのアクセス制御は、project とアプリケーションの両方に適用されます。

- Project roles
    - **Can Edit**：project の削除を除き、project への完全なアクセス権を持ちます。
    - **Can Launch**：**Launchpad** で project を表示し、許可されたアプリケーションだけを使用できます。
- Application roles
    - アプリケーションのビジネスロジックに基づいて agent が自動生成します。
    - Project のメンバーとして追加された後にのみ割り当てられます。

:::tip[独自のロールを割り当てたい場合]
Prompt にロールと権限範囲を記載してください。Agent はそれを自動生成されたロールと比較します。指定したロールが生成されたロールと競合する場合、agent が確認します。
:::
:::caution[アプリケーションロールの割り当ては必須です]
**Launchpad** でアプリケーションにアクセスするには、アプリケーションロールが割り当てられている必要があります。Workspace/project owner であっても、アプリケーションロールがない場合はそのアプリケーションを表示できません。
:::

### バージョン管理
Tier0 上のアプリケーションには 3 つの状態があります。

- **Draft**：アプリケーションの最新状態です。デプロイしない限り、このバージョンへの変更は他のバージョンに影響しません。
- **Snapshot**：snapshot 作成時点のアプリケーションを保存します。Snapshot バージョンをデプロイすると、現在の **Active** バージョンが置き換えられます。
- **Active**：現在オンラインで稼働しているアプリケーションです。

:::tip[バージョン切り替え]
- Draft をデプロイすると、active アプリケーションは新しいバージョンに更新されます。
- Snapshot をデプロイすると、active アプリケーションは以前のバージョンにロールバックされます。
:::

### 外部へエクスポート
アプリケーションの準備ができたら、**Preview** ページから外部のサードパーティ環境または Tier0 Enterprise 向けにエクスポートできます。

- **Download Source Code**：二次開発用にアプリケーションのソースコードをエクスポートします。
- **Export Bundle**：**Tier0 Enterprise** でローカルインポートするための専用エクスポートです。

:::tip[Snapshot のソースコードをダウンロードする]
Snapshot を保存してからダウンロードすると、その snapshot バージョンのソースコードを取得できます。
:::
