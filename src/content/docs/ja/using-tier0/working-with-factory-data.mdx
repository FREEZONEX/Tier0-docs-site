MQTT と API を通じて UNS データを操作できます。

## MQTT
MQTT clients は、Tier0 で生成された credentials を使って UNS broker に接続できます。
:::note
**MQTTX**、**MQTT Explorer**、**Node-RED** などの MQTT clients を使って broker に接続し、messages を publish/subscribe できます。
:::
### MQTT Credentials を生成する
Tier0 の **Edge** タブで新しい credential を作成し、記録します。

### MQTT Clients を接続する

:::tip
以下の clients は、credentials を使って UNS broker に接続する方法を示す例です。
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a> をインストールして開きます。
2. UNS broker の情報と生成された credentials を使って connection を追加します。
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 

  </TabItem>
  <TabItem label="MQTT Explorer">

1. <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a> をインストールして開きます。
2. UNS broker の情報と生成された credentials を使って新しい connection を追加します。
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 
3. Change the client ID to the credential ID in **ADVANCED** before connecting.

  </TabItem>
  <TabItem label="Node-RED">
      - **Event Flow** を使用 - Tier0 内の Node-RED ベースのデータ処理モジュールです。
          1. **Flows** で **Event Flow** を作成し、`mqtt in` node から開始します。
          2. node 内で UNS broker を **Server**（flow と同じ名前）として選択し、**Topic** を UNS model に設定します。
      - **独立した Node-RED Instance** を使用
          1. <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> instance をインストールして開きます。
          2. `mqtt in` node に、次の情報で server を追加します。
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 8883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### 接続をテストする
<Steps>
1. client status が正常であることを確認します。
2. UNS model topic をコピーし、client から message を publish します。
</Steps>

## API

### Cloud v2 のデータ取得

Cloud v2 は `https://<your-cloud-host>/openapi/v2` と `x-api-key` を使用します。以下は業務レコードと実際の時系列サンプルを取得する例です。Edge と Enterprise には適用されません。

まず `POST /uns/metadata:find` に `{"kind":"collection","filter":{},"page":{"mode":"offset","page":1,"size":20}}` を送信します。選択したコレクションの `data.items[].id` が `collectionId` です。`records:find` が返すレコードの `id` を `recordId` として使用します。どちらも UNS パスではありません。

#### 業務レコードを検索: `records:find`

<Tabs syncKey="uns-api-language">
  <TabItem label="JavaScript">

```js
const base = process.env.TIER0_BASE_URL; // https://<your-cloud-host>/openapi/v2
const collectionId = process.env.TIER0_COLLECTION_ID;
const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/records:find`, {
  method: "POST",
  headers: { "content-type": "application/json", "x-api-key": process.env.TIER0_API_KEY },
  body: JSON.stringify({"filter": {"status": "running"}, "limit": 20}),
});
const result = await response.json();
if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
console.log(result.data);
```

  </TabItem>
  <TabItem label="Python">

```python
import os
import requests

response = requests.post(
    f"{os.environ['TIER0_BASE_URL']}/uns/collections/{os.environ['TIER0_COLLECTION_ID']}/records:find",
    headers={"x-api-key": os.environ["TIER0_API_KEY"]},
    json={"filter": {"status": "running"}, "limit": 20},
    timeout=30,
)
response.raise_for_status()
result = response.json()
if result["code"] != 0:
    raise RuntimeError(result.get("error", result.get("msg")))
print(result["data"])
```

  </TabItem>
  <TabItem label="cURL">

```bash
curl --fail-with-body -X POST "$TIER0_BASE_URL/uns/collections/${TIER0_COLLECTION_ID}/records:find" \
  -H "content-type: application/json" \
  -H "x-api-key: $TIER0_API_KEY" \
  -d '{"filter": {"status": "running"}, "limit": 20}'
```

  </TabItem>
</Tabs>

#### 過去のサンプルを検索: `samples:find`

<Tabs syncKey="uns-api-language">

`samples:latest` は各レコードの `{recordId, sample}` を `data.series` に返します。サンプルがなければ `sample` は `null` です。`samples:find` は `data.items` と `data.pageInfo` を返します。`from` と `to` は Unix ミリ秒で、範囲は `[from, to)` です。`temperature` などのフィルターは業務フィールドを直接参照し、返却値は各サンプルの `data` に入ります。
