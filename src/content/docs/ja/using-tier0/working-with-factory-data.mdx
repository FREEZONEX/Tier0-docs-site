MQTT と API を通じて UNS データを操作できます。

## MQTT
Tier0 で生成した認証情報を使って MQTT クライアントを UNS broker に接続できます。
:::note
**MQTTX**、**MQTT Explorer**、**Node-RED** などのクライアントで broker に接続し、メッセージを配信・購読できます。
:::
### MQTT 認証情報を生成する
**Connect** > **Source** > **MQTT Device** で MQTT 認証情報を生成し、記録します。
:::note[Tier0 Edge の例外]
Tier0 Edge の外部接続には認証情報が不要です。
:::
### MQTT クライアントを接続する

:::tip
- UNS broker には次の TCP と WSS のアドレスで接続できます。
    - mqtt://host:1883
    - mqtts://host:8883
    - ws://host:8083/mqtt
    - wss://host:8084/mqtt
- 以下では TLS を使用しない TCP 接続を例にします。
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a> をインストールして開きます。
2. UNS broker の情報と生成した認証情報で接続を追加します。
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```

  </TabItem>
  <TabItem label="MQTT Explorer">

1. <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a> をインストールして開きます。
2. UNS broker の情報と生成した認証情報で新しい接続を追加します。
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```
3. 接続前に **ADVANCED** で Client ID を認証情報の ID に変更します。

  </TabItem>
  <TabItem label="Node-RED">
- **Event Flow** を使用：Tier0 の Node-RED ベースのデータ処理モジュール。

1. **Flows** で **Event Flow** を作成し、`mqtt in` ノードから始めます。
2. ノードの **Server** に UNS broker（Flow と同じ名前）を選び、**Topic** に UNS モデルを指定します。

- **独立した Node-RED インスタンス**を使用

1. <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> をインストールして開きます。
2. `mqtt in` ノードに次の情報でサーバーを追加します。
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 1883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### 接続をテストする
<Steps>
1. クライアントの状態が正常であることを確認します。
2. UNS モデルの Topic をコピーし、クライアントからメッセージを配信します。
</Steps>

## API

### 基本情報

- **Base URL**: `https://<your-tier0-host>/openapi/v2`
- **Authentication**: Tier0 で取得した API キーを `x-api-key` ヘッダーに指定します。

### リクエスト例

- `POST /uns/metadata:find` — Collections を一覧表示して Collection ID を取得
  :::note
  `data.items` で対象の Collection を探し、その `id` をコピーします。最初のページにない場合は `data.pageInfo` を確認して次のページを取得します。
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const response = await fetch(`${base}/uns/metadata:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data.items);
  ```

    </TabItem>
    <TabItem label="Python">

  ```python
  import requests

  response = requests.post(
      "https://your-tier0-host/openapi/v2/uns/metadata:find",
      headers={"x-api-key": "your-api-key"},
      json={"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}},
      timeout=30,
  )
  response.raise_for_status()
  result = response.json()
  if result["code"] != 0:
      raise RuntimeError(result.get("error", result.get("msg")))
  print(result["data"]["items"])
  ```

    </TabItem>
    <TabItem label="cURL">

  ```bash
  curl --fail-with-body -X POST "https://your-tier0-host/openapi/v2/uns/metadata:find" \
    -H "content-type: application/json" \
    -H "x-api-key: your-api-key" \
    -d '{"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}'
  ```

    </TabItem>
  </Tabs>

- `POST /uns/collections/{collectionId}/records:find` — Records を一覧表示して Record ID を取得
  :::note
  - `your-collection-id` を `metadata:find` で取得した ID に置き換えます。
  - `data.items` で対象の Record を探し、その `id` をコピーします。最初のページにない場合は、利用できるとき `data.pageInfo.nextCursor` を次のリクエストの `cursor` に指定します。
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/records:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data);
  ```

    </TabItem>

      timeout=30,
  )
  response.raise_for_status()

- `POST /uns/collections/{collectionId}/samples:find` — 指定期間の Samples を取得
  :::note
  - `your-collection-id` を `metadata:find` で取得した ID に置き換えます。
  - `recordIds` の `record_123` を `records:find` で取得した Record ID に置き換えます。
  - `from` と `to` に取得期間を設定します。
  - この例は `temperature` でも絞り込みます。期間内の全 Samples が必要な場合や Collection が別のフィールドを使う場合は、この条件を削除します。
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/samples:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"recordIds": ["record_123"], "from": 1792454400000, "to": 1792540800000, "filter": {"temperature": {"$gt": 20}}, "limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data);
  ```
