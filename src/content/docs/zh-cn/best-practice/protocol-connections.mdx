本节以 OPC UA、Modbus 和 API 等常见数据类型为例，展示如何通过 **数据连接** 将数据源连接到 **UNS**。

## OPC UA

### 配置数据流

<Steps>
1. 进入 Tier0 的 **数据流程**，创建一个 **数据连接**。
2. 在数据流中加入 `inject`，`OPC UA Client` 和 `mqtt out` 节点。
3. 按顺序连接节点，并双击每个节点配置详细信息。
</Steps>
- `inject`
    1. 单击左下角 **add** 添加一条属性。
    2. 按照以下内容配置属性。

        ```json
        {
          "msg.payload": "[multiple data tags]",
          "msg.topic": "multiple"
        }
        ```
- `OPC UA Client`
    ```json
    "Endpoint": "<OPC UA 服务器地址和端口>", //e.g. opc.tcp://127.0.0.1:4850
    "Action": "SUBSCRIBE",
    "Interval": "<数据采集频率>" //e.g. 10 秒
    ```
- `mqtt out`
    ```json
    "Server": "<内置 UNS broker>", //与数据流同名
    "Topic": "<UNS 模型>",
    ```
4. 部署并触发数据流。

## Modbus
### 配置数据流

1. 在数据流中加入 `modbus-read` 和 `mqtt out` 节点。
2. 双击节点配置信息。
    - `modbus-read`
        - **Settings**
          - **FC**：选择 Modbus 功能码。例如，FC 3 表示读取保持寄存器。
          - **Address**：设置起始寄存器地址。例如，从 0 开始读取。
          - **Quantity**：设置要连续读取的寄存器数量。
          - **Poll Rate**：设置 Modbus 轮询频率。例如，每 10 秒读取一次。
          - **Server**：选择或创建 Modbus 服务器，配置 IP、端口和协议。
        - **Server**
          - **Host**：Modbus 服务器 IP。
          - **Port**：Modbus 服务器端口。
    - `mqtt out`
        ```json
        "Server": "<内置 UNS broker>", //与数据流同名
        "Topic": "<UNS 模型>",
        ```
3. 部署数据流。

## API
### 配置数据流

1. 在数据流中加入 `inject`，`http request` 和 `mqtt out` 节点。
2. 双击节点配置信息。
    - `http request`
        ```json
        "Method": "<API method>",
        "URL": "<API URL>",
        "Return": "a parsed JSON object",
        "Headers": "<API headers>"
        ```
    - `mqtt out`
        ```json
        "Server": "<内置 UNS broker>", //与数据流同名
        "Topic": "<UNS 模型>",
        ```
3. 部署数据流。
