Tier0 提供三个版本：
- **Edge** - 开源版，可通过 Docker 在本地运行。
- **Cloud** - 云端托管 SaaS。
- **Enterprise** - 面向企业环境的私有化部署版本。

请参阅 [选择最合适的版本](../choosing-version/) 来判断哪个版本最符合用户需求。

## 安装 Tier0

<Tabs syncKey="edition">
	<TabItem label="Cloud">

		在体验 Tier0 Cloud 之前，需要申请试用账号。
		<Steps>
		1. 在 [注册 Tier0](https://tier0.dev/signup) 页面注册账号。
		2. 用发到邮箱的验证码进行验证后，使用注册账号登录。
		3. 创建一个工作空间并开始体验 Tier0.
	</Steps>
	
	</TabItem>
	<TabItem label="Enterprise">
#### 环境要求
- 标准部署
	- 最少：4 台虚拟机
	- 各 VM 类型的基线配置：
		- App：8C / 32G / 100G
		- Database：4C / 8G / 500G
		- Witness：2C / 4G / 40G
- 高可用部署
	- 最少：6 台虚拟机
	- 各 VM 类型的基线配置：
		- App (Swarm)：8C / 32G / 100G x 3
		- Database：4C / 8G / 500G x 2
		- Witness：2C / 4G / 40G

:::tip[硬件要求可能会变化]
Enterprise 的硬件要求会随部署场景变化。
:::

:::note
详细部署信息见 [高可用部署方案](../../reference/high-availability-deployment/)。
:::
#### 操作步骤
<Steps>
1. 从供应商处获取安装包，并完成校验。
		```bash
		sha256sum -c tier0-enterprise-offline-standard-YYYYmmddTHHMMSS.tar.gz.sha256
		```
2. 解压安装包。
		```bash
		tar -xzf tier0-enterprise-offline-standard-YYYYmmddTHHMMSS.tar.gz
		cd tier0-enterprise-offline-standard-YYYYmmddTHHMMSS
		```
3. 根据部署信息编辑 `install.env`，然后开始部署。
		```bash
		vi install.env
		bash install.sh
		```
</Steps>

#### 常用维护操作
- 在不安装 Enterprise 的情况下检查部署环境。
		```bash
		./install.sh --check-only
		```
- 部署失败后清理所有节点。
		```bash
		./full-cleanup.sh --env install.env --yes
		```
		:::caution[影响说明]
		此命令会清除全部 Tier0 运行时数据和数据库备份，但会保留虚拟机、操作系统以及已安装的 Docker 软件。
		:::
- 安装完成后会生成部署报告。
		```text
		runtime/install-reports/<timestamp>/deployment-report.md
		```
		:::caution[报告中出现 **FAIL** 时应该怎么做]
		如果报告中包含任何 **FAIL** 项，请不要交付项目，请先联系支持团队。
		:::

	<TabItem label="Edge">

	#### 环境要求
	- 至少 4 核 CPU、8 GB RAM、100 GB 磁盘
	- Ubuntu 24.04，或安装了 Docker 和 Git 的 Windows 10/11
	#### 操作步骤
	<Steps>
	1. 从 GitHub 克隆 Tier0-Edge 仓库到你的服务器，并进入项目目录。

		```bash
		git clone https://github.com/FREEZONEX/Tier0-Edge
		cd Tier0-Edge/deploy
		```

	2. 根据你的环境，在 `.env.default` 中按需编辑下表列出的参数。
	
		```bash
		cp .env.default .env
		vi .env
		:wq!
		```

		:::note[需要配置的参数]

		| 字段 | 类型 | 说明 | 示例 |
		|------|------|------|------|
		| VOLUMES_PATH | string | 项目数据的存储路径 | Linux 上为 `/srv/tier0/data`；Windows Bash 中为 `D:/tier0/data` 或 `/d/tier0/data` |
		| ENTRANCE_DOMAIN/ENTRANCE_PORT | string | Tier0 访问入口（IP/域名 + 端口） | `192.168.1.10` / `8088` |
		| LANGUAGE | enum | zh-CN / en-US | `zh-CN` |
		| ADMIN_INIT_PASSWORD | string | 管理员用户的初始密码 | 一个私有强密码 |
		| COMPOSE_PROJECT_NAME/PORT_OFFSET | string | 隔离同一主机上运行的多个实例 | `edge_lab` / `100` |

		:::
	3. 运行安装脚本，并检查安装状态。

		```bash
		bash bin/install.sh
		bash bin/compose.sh ps # 检查容器状态
		bash bin/compose.sh logs -f backend # 查看 backend 容器日志
		curl -fsS http://127.0.0.1:8088/readyz # 检查 backend 服务是否 ready
		```

		:::caution
		不要编辑 `deploy/.env.runtime`；它包含生成的密钥和解析后的运行时配置值。
		:::
	4. 使用配置好的访问入口和默认管理员账号访问 Tier0：
		- 用户名：`tier0`
		- 密码：`.env` 中 `ADMIN_INIT_PASSWORD` 的值；如果未设置，则为 `tier0`。

	</Steps>
