[Tier0 Builder Skills 仓库](https://github.com/FREEZONEX/Tier0-Builder-Skill/tree/feature/cloud-new-architecture-migration)的 `feature/cloud-new-architecture-migration` 分支目前包含 6 个 Skill，分别处理需求、应用构建、平台对齐、浏览器能力、响应式设计和预览故障。

## `app-srs`

用于创建、转换或修订工业企业应用的需求规格说明（SRS）。它梳理业务角色、流程、状态、校验和异常，限定首版范围，默认保存到 `specs/spec.md`。首次构建应用时，除非用户只要求需求文档或仍需澄清，它会继续交给 `app-builder`。

```text
使用 $app-srs 为汽车零部件工厂设计质量异常管理系统。
```

## `app-builder`

根据需求或 `specs/spec.md` 构建可运行的首版应用，或为现有应用增加重要业务模块。首次构建时，必要情况下先调用 `app-srs`。普通字段、文案、样式和局部 UI 修复无需完整 Builder 流程。

它会检查功能入口与可执行路径、真实数据和状态变化、校验与角色权限，以及构建、预览和交互验证。列表页面适用时会采用目标脚手架的 `MetaListPage`，并连接真实服务和权限。

```text
使用 $app-builder 根据 specs/spec.md 构建首版应用。
```

## `align-platform-app`

将导入的应用迁移到 Tier0 脚手架，或使现有应用与当前脚手架契约一致。适用于旧版 Tier0 应用、自有 SQL 数据库或浏览器存储的应用，以及需要完整更新或局部平台修复的脚手架应用。

它以[云架构脚手架](https://github.com/FREEZONEX/Tier0-App-Scaffold/tree/feature/cloud-new-architecture-migration)的精确提交为基准，对齐运行时、路由、Gateway 角色和平台契约，同时保留业务行为。完整云迁移会通过 `@tier0/sdk-v2` 将应用自有的持久记录迁至 Tier0 UNS collections；原数据库的历史记录如需保留，还要单独导入 UNS。完成构建和运行验证后才写入 `package.json` 中的脚手架版本标记。

```text
使用 $align-platform-app 将此应用对齐最新 Tier0 脚手架，并保留业务代码。
```

:::caution
局部修复不代表已完成全部数据迁移或脚手架更新。
:::

## `browser-platform-capabilities`

指导二维码／条码扫描、拍照、定位、录音、文件读取和剪贴板访问。它按目标设备选择浏览器 API 和后备方案，检查安全上下文、权限及 iframe/WebView 限制；取消或失败时保留表单输入，并区分后备数据与实时采集数据。实现后验证成功、拒绝、重试和清理路径。

```text
使用 $browser-platform-capabilities 为巡检表单添加拍照功能，并提供文件上传后备方案。
```

:::note
此 Skill 不提供统一的 Tier0 设备 SDK，也不能保证所有浏览器或嵌入式容器都允许这些 API。
:::

## `responsive-craft`

处理复杂断点、协同的固定与滚动区域，以及多视口审查和预览。局部溢出或控件裁切可直接修复。`audit` 审查并修复现有布局；`build` 从零构建响应式页面；`preview` 启动多断点实时预览。

```text
使用 $responsive-craft audit 修复此仪表板的移动端布局。
```

```text
使用 $responsive-craft preview 预览 375、768、1024 和 1440 px 断点。
```

## `preview-runtime-stability`

诊断托管预览的安装、启动、就绪状态、角色、端口和 HMR 故障，不负责构建业务功能。适用于依赖或锁文件错误、Vite/TanStack Start 启动故障、`5173` 端口冲突、`/api/health` 或预览角色错误、`artifact.toml` 不匹配，以及 HMR 频繁整页重载。先读取相关错误，修复有证据支持的原因，仅在必要时重启，并验证原故障、健康检查和受影响路由。

```text
使用 $preview-runtime-stability 诊断“Preview loading timed out”。
```

## Skill 选择指南

- 需求创建或修订：`app-srs`，首次构建通常再交给 `app-builder`。
- 首版应用或重要业务扩展：`app-builder`。
- 迁移或脚手架对齐：`align-platform-app`。
- 六种浏览器能力：`browser-platform-capabilities`。
- 复杂响应式工作：`responsive-craft`；托管预览故障：`preview-runtime-stability`。
