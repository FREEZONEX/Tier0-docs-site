## 连接与认证

- **基础 URL**：`https://<your-tier0-host>/openapi/v2`
- **认证**：在 `x-api-key` 请求头中发送 Tier0 API Key。

## 检查结果

- 对 `/uns/` 请求同时检查 HTTP 状态和响应体。成功响应的状态为 `2xx` 且 `code: 0`，结果在 `data` 中。
- 失败时查看 `error.code`，并保留 `requestId` 以便排查。
- 批量请求即使返回 HTTP `200`，也要逐项检查，部分项目可能失败。

## 重试写入

- 查看 `error.execution`，判断写入是否未开始、已回滚、已提交或结果未知。
- 仅当 `error.retry.safe` 为 `true` 时，才使用相同幂等键重试同一请求。如果给出等待时间，至少等待 `error.retry.afterMs` 或 `Retry-After` 响应头指定的时长。
- 如果批量请求部分提交，先核对成功项目，再提交剩余工作。若结果未知且响应未确认可安全重试，先验证写入是否生效。
