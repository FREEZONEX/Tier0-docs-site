通过 MCP 将 AI Agent 连接到 Tier0。Agent 可以在你授予的权限范围内查找并调用平台 API。

<AgentIcons />

:::note[开始之前]
- 从 **设置** > **MCP 接入** 获取 MCP URL。
- Agent 客户端需要支持通过 HTTP 连接远程 MCP。
:::

## 连接 Agent

以下以 Codex 为例。

<Tabs syncKey="edition">
  <TabItem label="手动添加">
    1. 在 **设置** > **插件** > **MCP** 中添加 MCP 服务器，填写从 Tier0 获取的 URL。
    2. 在 Tier0 的 **设置** > **API Keys** > **Personal Keys** 中创建具有所需权限的个人 API Key。
    3. 将个人 API Key 添加到 Codex 中的 MCP 服务器：
       ```json
       { "Authorization": "Bearer <your-personal-api-key>" }
       ```
    4. 让 Agent 调用 `whoami`，检查连接。
  </TabItem>
  <TabItem label="命令行">
    1. 在 PowerShell 中运行以下命令，并在浏览器中登录：
       ```bash
       codex mcp add tier0 --url https://your-tier0-url/mcp --oauth-client-registration dcr
       ```
    2. 授权 Workspace 并授予相应权限：
       ```bash
       codex mcp login tier0 --oauth-client-registration dcr
       ```
    3. 让 Agent 调用 `whoami`，检查连接。
  </TabItem>
</Tabs>

## 使用 Agent 操作 Tier0

| MCP 工具 | 用途 |
| --- | --- |
| `whoami` | 检查身份和权限。 |
| `docs` | 阅读 API 文档。 |
| `search` | 查找 API 操作。 |
| `execute` | 调用 API 操作。 |

先让 Agent 使用 `docs` 和 `search` 找到所需操作，再使用 `execute` 调用。例如：

```text
读取我的 Workspace 中 `Plant/Line1/Metric/Temperature` 的当前值。
```

:::tip[未获得结果时]
写入后让 Agent 重新读取结果。如果结果显示 `outcome=unknown`，先检查当前状态，再决定是否重试。
:::
