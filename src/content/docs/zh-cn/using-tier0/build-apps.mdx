## 什么是 Tier0 应用

Tier0 应用具备以下特点：
- 它是一个 **Docker 容器**。
- 它由你与 **App Builder** 的对话生成，零代码。
- 它使用 **UNS** 中已有的工业数据，并且可以将数据*回写*到 **UNS**。
- 它可以使用 **事件流程** 实现逻辑。

## 如何部署 Tier0 应用

### 构建 Tier0 应用
<Steps>
1. 登录 Tier0，进入 **应用** > **项目**，为应用创建一个项目。
2. 在项目中创建应用，随后跳转到应用构建页面。
3. 在对话框中写下应用需求。
</Steps>
:::tip[Prompt 中应包含什么]
请确保在 prompt 中说明以下信息：
- 使用 UNS 模型 *[uns_model]* 作为数据源，并使用 *[uns_model]* 作为回写目标。
- （可选）创建 UNS 模型，并在 **数据连接** 中创建数据流来连接数据源。
- 在 **事件流程** 中创建数据流，用于触发异常报警/低健康分/其他事件。
:::
<Steps>
4. 开始构建应用，并在预览时通过与 LLM 对话按需修改。
5. 单击 **部署** 完成应用构建。
</Steps>

### 在 Tier0 Enterprise 上部署应用
<Steps>
1. 在项目中找到并进入该应用。
2. 编辑应用，在编辑页面中单击 **...** 选择 **导出运行包**。
3. 登录 Tier0 Enterprise，进入 **项目**，为应用创建一个项目
4. 单击 **导入应用** 并上传运行包。
</Steps>
