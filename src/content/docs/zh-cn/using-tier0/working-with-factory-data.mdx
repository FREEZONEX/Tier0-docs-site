你可以通过 MQTT 和 API 操作 UNS 数据。

## MQTT
MQTT 客户端可以使用 Tier0 生成的凭据连接到 UNS broker。
:::note
你可以使用 **MQTTX**、**MQTT Explorer** 和 **Node-RED** 等 MQTT 客户端连接 UNS broker，并发布/订阅消息。
:::
### 生成 MQTT 凭据
在 Tier0 的 **Edge** 页签创建新的凭据，并记录下来。

### 连接 MQTT 客户端

:::tip
以下客户端作为示例，用来展示如何使用凭据连接 UNS broker。
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. 安装并打开 <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a>。
2. 使用 Tier0 UNS broker 信息和生成的凭据添加连接。
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 

  </TabItem>
  <TabItem label="MQTT Explorer">

1. 安装并打开 <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a>。
2. 使用 broker 信息和生成的凭据添加新连接。
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 
3. 连接前，在 **ADVANCED** 中将 client ID 改为凭据 ID。

  </TabItem>
  <TabItem label="Node-RED">
      - 使用 **事件流程** - Tier0 中基于 Node-RED 的数据处理模块。
          1. 在 **事件流程** 中创建数据流，并用 `mqtt in` 节点作为起点。
          2. 在节点中选择 UNS broker 作为 **Server**（与 flow 同名），并将 **Topic** 设置为 UNS 模型。
      - 使用**独立 Node-RED 实例**
          1. 安装并打开 <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> 实例。
          2. 在 `mqtt in` 节点中使用以下信息添加 server。
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 8883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### 测试连接
<Steps>
1. 确认 client 状态正常。
2. 复制一个 UNS 模型 topic，并通过 client 向它发布一条 message。
</Steps>

## API

### Cloud v2 数据读取

Cloud v2 使用 `https://<your-cloud-host>/openapi/v2` 和 `x-api-key`。以下示例读取业务记录与真实时序采样，不适用于 Edge 或 Enterprise。

先调用 `POST /uns/metadata:find`，请求 `{"kind":"collection","filter":{},"page":{"mode":"offset","page":1,"size":20}}`。选中集合的 `data.items[].id` 是 `collectionId`。`records:find` 返回记录的 `id`，可作为采样查询的 `recordId`。两者都不是 UNS 路径。

#### 查询业务记录: `records:find`

<Tabs syncKey="uns-api-language">
  <TabItem label="JavaScript">

```js
const base = process.env.TIER0_BASE_URL; // https://<your-cloud-host>/openapi/v2
const collectionId = process.env.TIER0_COLLECTION_ID;
const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/records:find`, {
  method: "POST",
  headers: { "content-type": "application/json", "x-api-key": process.env.TIER0_API_KEY },
  body: JSON.stringify({"filter": {"status": "running"}, "limit": 20}),
});
const result = await response.json();
if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
console.log(result.data);
```

  </TabItem>
  <TabItem label="Python">

```python
import os
import requests

response = requests.post(
    f"{os.environ['TIER0_BASE_URL']}/uns/collections/{os.environ['TIER0_COLLECTION_ID']}/records:find",
    headers={"x-api-key": os.environ["TIER0_API_KEY"]},
    json={"filter": {"status": "running"}, "limit": 20},
    timeout=30,
)
response.raise_for_status()
result = response.json()
if result["code"] != 0:
    raise RuntimeError(result.get("error", result.get("msg")))
print(result["data"])
```

  </TabItem>
  <TabItem label="cURL">

```bash
curl --fail-with-body -X POST "$TIER0_BASE_URL/uns/collections/${TIER0_COLLECTION_ID}/records:find" \
  -H "content-type: application/json" \
  -H "x-api-key: $TIER0_API_KEY" \
  -d '{"filter": {"status": "running"}, "limit": 20}'
```

  </TabItem>
</Tabs>

#### 查询历史采样: `samples:find`

<Tabs syncKey="uns-api-language">
  <TabItem label="JavaScript">

```js
const base = process.env.TIER0_BASE_URL; // https://<your-cloud-host>/openapi/v2
const collectionId = process.env.TIER0_COLLECTION_ID;
const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/samples:find`, {
  method: "POST",
  headers: { "content-type": "application/json", "x-api-key": process.env.TIER0_API_KEY },
  body: JSON.stringify({"recordIds": ["record_123"], "from": 1792454400000, "to": 1792540800000, "filter": {"temperature": {"$gt": 20}}, "limit": 20}),
});
const result = await response.json();
if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
console.log(result.data);
```

`samples:latest` 返回 `data.series`，每个请求的记录对应一个 `{recordId, sample}`；没有采样时 `sample` 为 `null`。`samples:find` 返回 `data.items` 和 `data.pageInfo`。`from`、`to` 是 Unix 毫秒，范围为 `[from, to)`。`temperature` 等筛选字段直接指业务字段；返回值位于每个采样的 `data`。
