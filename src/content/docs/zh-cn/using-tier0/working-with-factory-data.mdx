你可以通过 MQTT 和 API 操作 UNS 数据。

## MQTT
Tier0 生成的凭据可用于让 MQTT 客户端连接 UNS broker。
:::note
可以使用 **MQTTX**、**MQTT Explorer** 和 **Node-RED** 等客户端连接 broker，发布和订阅消息。
:::
### 生成 MQTT 凭据
在 **Connect** > **Source** > **MQTT Device** 中生成 MQTT 凭据并记录。
:::note[Tier0 Edge 版本的例外]
Tier0 Edge 的外部连接不需要凭据。
:::
### 连接 MQTT 客户端

:::tip
- UNS broker 支持通过以下 TCP 和 WSS 地址连接：
    - mqtt://host:1883
    - mqtts://host:8883
    - ws://host:8083/mqtt
    - wss://host:8084/mqtt
- 以下连接示例使用未启用 TLS 的 TCP。
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. 安装并打开 <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a>。
2. 使用 UNS broker 信息和生成的凭据添加连接。
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```

  </TabItem>
  <TabItem label="MQTT Explorer">

1. 安装并打开 <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a>。
2. 使用 UNS broker 信息和生成的凭据添加新连接。
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```
3. 连接前在 **ADVANCED** 中将 Client ID 改为凭据 ID。

  </TabItem>
  <TabItem label="Node-RED">
      - 使用 **Event Flow**：Tier0 中基于 Node-RED 的数据处理模块。

          1. 在 **Flows** 中创建 **Event Flow**，以 `mqtt in` 节点开始。
          2. 在节点中选择 UNS broker 作为 **Server**（与 Flow 同名），并将 **Topic** 设置为 UNS 模型。

      - 使用**独立的 Node-RED 实例**

          1. 安装并打开 <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> 实例。
          2. 在 `mqtt in` 节点中使用以下信息添加服务器。
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 1883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### 测试连接
<Steps>
1. 确认客户端状态正常。
2. 复制 UNS 模型 Topic，通过客户端向其发布一条消息。
</Steps>

## API

### 基本信息

- **Base URL**: `https://<your-tier0-host>/openapi/v2`
- **Authentication**: 将从 Tier0 获取的 API Key 放在 `x-api-key` 请求头中。

### 请求示例

- `POST /uns/metadata:find` — 列出 Collections 并获取 Collection ID
  :::note
  在 `data.items` 中找到目标 Collection 并复制其 `id`。如果第一页没有，检查 `data.pageInfo` 并请求下一页。
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const response = await fetch(`${base}/uns/metadata:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data.items);
  ```

    </TabItem>
    <TabItem label="Python">

  ```python
  import requests

  response = requests.post(
      "https://your-tier0-host/openapi/v2/uns/metadata:find",
      headers={"x-api-key": "your-api-key"},
      json={"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}},
      timeout=30,
  )
  response.raise_for_status()
  result = response.json()
  if result["code"] != 0:
      raise RuntimeError(result.get("error", result.get("msg")))
  print(result["data"]["items"])
  ```

    </TabItem>
    <TabItem label="cURL">

  ```bash
  curl --fail-with-body -X POST "https://your-tier0-host/openapi/v2/uns/metadata:find" \
    -H "content-type: application/json" \
    -H "x-api-key: your-api-key" \
    -d '{"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}'
  ```

    </TabItem>
  </Tabs>

- `POST /uns/collections/{collectionId}/records:find` — 列出 Records 并获取 Record ID
  :::note
  - 将 `your-collection-id` 替换为 `metadata:find` 返回的 ID。
  - 在 `data.items` 中找到目标 Record 并复制其 `id`。如果第一页没有，且返回了 `data.pageInfo.nextCursor`，请将其用作下一次请求的 `cursor`。
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/records:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data);
  ```

    </TabItem>
    <TabItem label="Python">

  response = requests.post(

      timeout=30,
  )
  response.raise_for_status()

- `POST /uns/collections/{collectionId}/samples:find` — 获取指定时间范围内的 Samples
  :::note
  - 将 `your-collection-id` 替换为 `metadata:find` 返回的 ID。
  - 将 `recordIds` 中的 `record_123` 替换为 `records:find` 返回的 Record ID。
  - 将 `from` 和 `to` 设置为需要的时间范围。
  - 本示例还按 `temperature` 筛选。如果需要范围内的全部 Samples，或者 Collection 使用其他字段，请移除该筛选条件。
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/samples:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"recordIds": ["record_123"], "from": 1792454400000, "to": 1792540800000, "filter": {"temperature": {"$gt": 20}}, "limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data);
  ```
