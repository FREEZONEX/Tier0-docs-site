你可以通过 MQTT 和 API 操作 UNS 数据。

## MQTT
MQTT 客户端可以使用 Tier0 生成的凭据连接到 UNS broker。
:::note
你可以使用 **MQTTX**、**MQTT Explorer** 和 **Node-RED** 等 MQTT 客户端连接 UNS broker，并发布/订阅消息。
:::
### 生成 MQTT 凭据
在 Tier0 的 **Edge** 页签创建新的凭据，并记录下来。

### 连接 MQTT 客户端

:::tip
以下客户端作为示例，用来展示如何使用凭据连接 UNS broker。
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. 安装并打开 <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a>。
2. 使用 Tier0 UNS broker 信息和生成的凭据添加连接。
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 

  </TabItem>
  <TabItem label="MQTT Explorer">

1. 安装并打开 <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a>。
2. 使用 broker 信息和生成的凭据添加新连接。
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 8883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ``` 
3. 连接前，在 **ADVANCED** 中将 client ID 改为凭据 ID。

  </TabItem>
  <TabItem label="Node-RED">
      - 使用 **事件流程** - Tier0 中基于 Node-RED 的数据处理模块。
          1. 在 **事件流程** 中创建数据流，并用 `mqtt in` 节点作为起点。
          2. 在节点中选择 UNS broker 作为 **Server**（与 flow 同名），并将 **Topic** 设置为 UNS 模型。
      - 使用**独立 Node-RED 实例**
          1. 安装并打开 <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a> 实例。
          2. 在 `mqtt in` 节点中使用以下信息添加 server。
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 8883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### 测试连接
<Steps>
1. 确认 client 状态正常。
2. 复制一个 UNS 模型 topic，并通过 client 向它发布一条 message。
</Steps>

## API
使用 **REST API** 操作 UNS 数据。
:::tip[如何使用 API]
OpenAPI base path 是 `/openapi/v1`，例如 `https://your-workspace.tier0.app/openapi/v1`，API key 通过 `x-api-key` header 传入。
:::

### 获取 API Key

API keys 位于 **Settings > API Keys**。不同 account type 允许创建的 key type 不同。
- **Service Key**：只能由 **Admin** 和 **Owner** 创建。
- **Personal Key**：任何人都可以创建，permission scope 与该 account 相同。
:::caution[Key permission vs Account permission]
Account permission 优先于 key permission。即使 key permission 设置为 **Full Access**，account 无权访问的数据仍然无法通过该 key 访问。
:::

### 示例

- `/uns/create`

  创建 UNS path 或 topic。使用 `namespace` 定义 node tree.

  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

      ```js
      const BASE_URL = process.env.TIER0_BASE_URL;
      const API_KEY = process.env.TIER0_API_KEY;

      const response = await fetch(`${BASE_URL}/uns/create`, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          'x-api-key': API_KEY,
        },
        body: JSON.stringify({
          namespace: [
            {
              name: 'DemoFactory',
              type: 'PATH',
              children: [
                {
                  name: 'Site_01',
                  type: 'PATH',
                  children: [
                    {
                      name: 'Production',
                      type: 'PATH',
                      children: [
                        {
                          name: 'Produced_Qty',
                          type: 'TOPIC',
                          topicType: 'METRIC',
                          displayName: 'Produced Quantity',
                          description: 'Produced quantity from the production line.',
                          enableHistory: true,
                          fields: [
                            { name: 'value', type: 'DOUBLE', unit: 'pcs' },
                          ],
                        },
                      ],
                    },
                  ],
                },
              ],
            },
          ],
        }),
      });

      const result = await response.json();
      console.log(result.data.results);
      ```

    </TabItem>
    <TabItem label="Python">

      ```python
      import os
      import requests

      base_url = os.environ["TIER0_BASE_URL"]
      api_key = os.environ["TIER0_API_KEY"]

      response = requests.post(
          f"{base_url}/uns/create",
          headers={"x-api-key": api_key},
          json={
              "namespace": [
                  {
                      "name": "DemoFactory",
                      "type": "PATH",
                      "children": [
                          {
                              "name": "Site_01",
                              "type": "PATH",
                              "children": [
                                  {
                                      "name": "Production",
                                      "type": "PATH",
                                      "children": [
                                          {
                                              "name": "Produced_Qty",
                                              "type": "TOPIC",
                                              "topicType": "METRIC",
                                              "displayName": "Produced Quantity",
                                              "description": "Produced quantity from the production line.",
                                              "enableHistory": True,
                                              "fields": [
                                                  {"name": "value", "type": "DOUBLE", "unit": "pcs"},
                                              ],
                                          },
                                      ],
                                  },
                              ],
                          },
                      ],
                  },
              ],
          },
          timeout=30,
      )
      response.raise_for_status()

      result = response.json()
      print(result["data"]["results"])
      ```

    </TabItem>
    <TabItem label="cURL">

      ```bash

        -H "content-type: application/json" \
        -H "x-api-key: $TIER0_API_KEY" \
        -d '{
          "namespace": [
            {
              "name": "DemoFactory",
      ```

- `/uns/read`

  读取一个或多个 UNS topics 的最新值和元数据。

  <Tabs syncKey="uns-api-language">

      ```js
        headers: {
      ```

- `/uns/update`

  通过 `path` 更新 UNS 节点。使用 `updateMask` 指定需要变更的字段。

  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

      ```js
      const BASE_URL = process.env.TIER0_BASE_URL;
      const API_KEY = process.env.TIER0_API_KEY;

      const response = await fetch(`${BASE_URL}/uns/update`, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          'x-api-key': API_KEY,
        },
        body: JSON.stringify({
          path: 'DemoFactory/Site_01/Production/Produced_Qty',
          displayName: 'Produced Quantity',
          description: 'Updated production output quantity.',
          updateMask: ['displayName', 'description'],
        }),
      });

      const result = await response.json();
      console.log(result.data);
      ```

    </TabItem>
    <TabItem label="Python">

      ```python
      import os
      import requests

      base_url = os.environ["TIER0_BASE_URL"]
      ```
