Tier0 使用 Marimo Notebook，通过 **Python** 脚本进行高级数据分析。

:::tip[开始前须知]
只有开启 **Enable History** 的 UNS 数据，才会作为可用数据源出现在 **Notebook** 中。
:::

<Steps>
1. 在 UNS 数据中选择 **VARIABLES** > **PostgreSQL** > **tenant_id** > **uns**。
2. 单击 **GENERATE WITH AI**，然后使用 **@** 选择要分析的变量。Notebook 支持 fuzzy match 来帮助查找变量。
3. 根据需要继续分析，或回滚生成结果。
</Steps>

:::tip[Notebook 中的 AI 辅助]
- Tier0 Cloud 可以直接使用 AI 辅助。
- Tier0 Enterprise 需要配置自己的 AI key。
:::
