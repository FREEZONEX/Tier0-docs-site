title: Referencia de API
description: Conecta con la API de Tier0, comprueba las respuestas y reintenta escrituras de forma segura.
---

## Conexión y autenticación

- **URL base**: `https://<your-tier0-host>/openapi/v2`
- **Autenticación**: Envía la clave API de Tier0 en la cabecera `x-api-key`.

## Comprobación de resultados

- Para solicitudes `/uns/`, comprueba el estado HTTP y el cuerpo. Una respuesta correcta tiene estado `2xx` y `code: 0`; el resultado está en `data`.
- En caso de error, consulta `error.code` y conserva `requestId` para investigar.
- En solicitudes por lotes, comprueba cada elemento incluso si el estado HTTP es `200`; algunos pueden haber fallado.

## Reintentos de escritura

- Consulta `error.execution` para saber si la escritura no comenzó, se revirtió, se confirmó o tiene un resultado desconocido.
- Solo si `error.retry.safe` es `true`, reintenta la misma solicitud con la misma clave de idempotencia. Si se indica una espera, respeta como mínimo `error.retry.afterMs` o la cabecera `Retry-After`.
- Si se confirmó parte de un lote, comprueba los elementos correctos antes de enviar el resto. Si el resultado es desconocido y no se confirma un reintento seguro, verifica primero si la escritura se aplicó.

## Glosario

- **Idempotencia**: Repetir una operación tiene el mismo efecto que ejecutarla una vez. Reutiliza la misma clave al reintentar una escritura compatible y usa una nueva para otra escritura independiente.
