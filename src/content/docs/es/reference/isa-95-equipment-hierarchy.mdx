La jerarquía de equipos ISA-95 describe cómo se estructuran los activos físicos y los sistemas de control dentro de una organización.

Se divide en los siguientes niveles:

- **Enterprise**: El nivel superior, que representa toda la organización. Incluye los procesos de negocio generales y las entidades de toma de decisiones, normalmente respaldadas por sistemas ERP.
- **Site**: Representa una ubicación geográfica o instalación específica. Cada site puede tener sus propios sistemas de gestión y control local de producción.
- **Area**: Una división operativa dentro de un site, a menudo un área funcional como empaquetado, ensamblaje o almacén.
- **Process Cell**: La unidad básica de fabricación dentro de un area. Incluye todo el equipo necesario para producir un producto específico o realizar una función específica.
- **Unit**: Una parte diferenciada del process cell, responsable de una función específica como mezclar, calentar o ensamblar.
- **Equipment Module**: Un equipo modular que realiza una tarea específica dentro de un unit. Por ejemplo, en una unidad de mezcla, el módulo podría ser un elemento calefactor.
- **Control Module**: El nivel más bajo, que representa dispositivos o controladores individuales como sensores, bombas, actuadores o lazos de control PID que gestionan el control directo de los procesos físicos.
