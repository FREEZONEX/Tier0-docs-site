La rama `feature/cloud-new-architecture-migration` del [repositorio Tier0 Builder Skills](https://github.com/FREEZONEX/Tier0-Builder-Skill/tree/feature/cloud-new-architecture-migration) contiene actualmente 6 Skills para requisitos, construcción de aplicaciones, alineación con la plataforma, capacidades del navegador, diseño adaptable y problemas de preview.

## `app-srs`

Es el punto de partida para los requisitos de aplicaciones industriales. Crea un SRS desde una solicitud, convierte un PRD o revisa un SRS existente. Define roles, flujos, estados, validaciones y excepciones; limita el alcance de la primera versión y guarda el documento en `specs/spec.md` de forma predeterminada. Para una aplicación nueva, continúa con `app-builder`, salvo que se pidan solo los requisitos o haga falta aclarar algo.

```text
Usa $app-srs para diseñar un sistema de gestión de incidencias de calidad para una fábrica de autopartes.
```

## `app-builder`

Construye una primera versión ejecutable o amplía sustancialmente una aplicación existente a partir de requisitos o `specs/spec.md`. Si es necesario, crea primero el SRS con `app-srs`. Los cambios corrientes de campos, textos, estilos y ajustes aislados de UI no requieren el flujo completo de Builder.

Comprueba las entradas y recorridos de las funciones comprometidas, los datos reales y cambios de estado, validaciones y permisos, además de la compilación, el preview y los flujos interactivos. En listas adecuadas utiliza `MetaListPage` del scaffold de destino, conectado a servicios y permisos reales.

```text
Usa $app-builder para construir la primera versión desde specs/spec.md.
```

## `align-platform-app`

Migra una aplicación importada al scaffold de Tier0 o alinea una aplicación existente con el contrato actual. Sirve para aplicaciones antiguas, con SQL propio, almacenamiento en navegador o persistencia simulada, y para actualizaciones completas o reparaciones acotadas de la plataforma.

Compara la aplicación con un commit exacto del [scaffold de arquitectura cloud](https://github.com/FREEZONEX/Tier0-App-Scaffold/tree/feature/cloud-new-architecture-migration). Conserva el comportamiento empresarial mientras alinea runtime, rutas, roles de Gateway y contratos de plataforma. Una migración cloud completa traslada los registros persistentes propios de la aplicación a Tier0 UNS collections mediante `@tier0/sdk-v2`; los registros históricos de la base de datos original requieren una importación aparte a UNS si se necesitan. Verifica la compilación y el funcionamiento antes de escribir la versión del scaffold en `package.json`.

```text
Usa $align-platform-app para alinear esta aplicación con el scaffold actual de Tier0 y conservar su código empresarial.
```

:::caution
Una reparación acotada no implica una migración completa de datos ni una actualización total del scaffold.
:::

## `browser-platform-capabilities`

Guía el uso de lectura QR y de códigos de barras, cámara, geolocalización, grabación de audio, lectura de archivos y portapapeles. Elige API del navegador y alternativas según el dispositivo; comprueba el contexto seguro, los permisos y las restricciones de iframe o WebView. Conserva los datos del formulario ante cancelaciones o errores e identifica las alternativas que no equivalen a una captura en vivo. Verifica éxito, denegación, reintento y limpieza.

```text
Usa $browser-platform-capabilities para añadir captura de fotos con carga de archivo alternativa a un formulario de inspección.
```

:::note
Esta Skill no proporciona un SDK de dispositivos unificado de Tier0 ni garantiza que todos los navegadores o contenedores permitan esas API.
:::

## `responsive-craft`

Gestiona puntos de ruptura complejos, zonas de desplazamiento y elementos fijos coordinados, y auditorías o previews en varios tamaños. Los desbordamientos aislados pueden corregirse directamente. `audit` revisa y repara un diseño existente; `build` crea una página adaptable; `preview` inicia una vista en varios puntos de ruptura.

```text
Usa $responsive-craft audit para reparar el diseño móvil de este panel.
```

```text
Usa $responsive-craft preview para ver 375, 768, 1024 y 1440 px.
```

## `preview-runtime-stability`

Diagnostica fallos de instalación, arranque, disponibilidad, rol, puerto y HMR del preview gestionado. No crea funciones empresariales. Abarca dependencias y lockfiles, Vite o TanStack Start, conflictos en el puerto `5173`, fallos de `/api/health`, roles de preview, discrepancias de `artifact.toml` y recargas completas frecuentes. Lee primero el error relevante, corrige la causa demostrada, reinicia solo si hace falta y verifica el fallo original, la salud y la ruta afectada.

```text
Usa $preview-runtime-stability para diagnosticar «Preview loading timed out».
```

## Guía de selección de Skills

- Crear o revisar requisitos: `app-srs`; normalmente entrega las aplicaciones nuevas a `app-builder`.
- Primera versión o ampliación empresarial importante: `app-builder`.
- Migración o alineación del scaffold: `align-platform-app`.
- Seis capacidades del navegador: `browser-platform-capabilities`.
- Diseño adaptable complejo: `responsive-craft`; fallos del preview gestionado: `preview-runtime-stability`.
