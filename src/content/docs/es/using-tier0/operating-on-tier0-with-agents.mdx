Conecta tu Agent de IA a Tier0 mediante MCP. El Agent puede buscar y usar las API de la plataforma dentro de los permisos que le concedas.

<AgentIcons />

:::note[Antes de empezar]
- Obtén la URL de MCP en **Settings** > **MCP Access**.
- El cliente del Agent debe admitir MCP remoto por HTTP.
:::

## Conectar el Agent

Se usa Codex como ejemplo.

<Tabs syncKey="edition">
  <TabItem label="Añadir manualmente">
    1. En **Settings** > **Plugin** > **MCP**, añade un servidor MCP con la URL obtenida en Tier0.
    2. En Tier0, crea una clave API personal con los permisos necesarios en **Settings** > **API Keys** > **Personal Keys**.
    3. Introduce la clave en el servidor MCP de Codex.
       ```json
       { "Authorization": "Bearer <your-personal-api-key>" }
       ```
    4. Pide al Agent que ejecute `whoami` para comprobar la conexión.
  </TabItem>
  <TabItem label="Línea de comandos">
    1. Ejecuta este comando en PowerShell e inicia sesión en el navegador:
       ```bash
       codex mcp add tier0 --url https://your-tier0-url/mcp --oauth-client-registration dcr
       ```
    2. Autoriza el Workspace y concede los permisos correspondientes:
       ```bash
       codex mcp login tier0 --oauth-client-registration dcr
       ```
    3. Pide al Agent que ejecute `whoami` para comprobar la conexión.
  </TabItem>
</Tabs>

## Operar Tier0 con el Agent

| Herramienta MCP | Uso |
| --- | --- |
| `whoami` | Comprueba la identidad y los permisos. |
| `docs` | Lee la documentación de la API. |
| `search` | Busca una operación de API. |
| `execute` | Llama a una operación de API. |

Pide primero al Agent que use `docs` y `search` para encontrar la operación y después `execute` para llamarla. Por ejemplo:

```text
Lee el valor actual de `Plant/Line1/Metric/Temperature` en mi Workspace.
```

:::tip[Si no obtienes resultados]
Después de escribir, pide al Agent que vuelva a leer el resultado. Si aparece `outcome=unknown`, comprueba el estado actual antes de reintentar.
:::
