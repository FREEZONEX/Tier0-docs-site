Crea aplicaciones industriales personalizadas mediante conversaciones con IA. Las aplicaciones pueden usar datos de fábrica e incluir capacidades integradas como control de acceso basado en roles, gestión de versiones y despliegue.

## Crear una app de Tier0
Antes de crear una aplicación, crea un project.

- El project se usa para clasificar aplicaciones y gestionar el control de acceso.
- Las aplicaciones dentro de un mismo project pueden funcionar como módulos relacionados de un sistema complejo.
- Los datos de cada project son independientes de los datos de otros projects.

### Escribir el prompt
Para que el agent genere una aplicación que se ajuste mejor a tus requisitos, asegúrate de que el prompt cubra ***al menos*** los siguientes aspectos.

- **Propósito de la aplicación**: ¿Cuál es el objetivo de la aplicación?
    ```text
    Crea una aplicación de mantenimiento de equipos para técnicos de fábrica.
    ```
- **Datos de la aplicación**: ¿Qué datos usa la aplicación y dónde están?

    <Tabs>
    <TabItem label="Platform Plan">
    [Conecta datos a UNS](../connect-data/) e indica el UNS topic en el prompt.
    ```text
    La aplicación debe usar el estado de los equipos, los registros de alarmas y el historial de mantenimiento del modelo UNS xxx.
    ```
    </TabItem>
    <TabItem label="Builder Plan">
    El agent simulará automáticamente los datos necesarios para el arranque durante la inicialización.
    </TabItem>
    </Tabs>
- **Función de la aplicación**: ¿Qué debe hacer la aplicación?
    ```text
    La aplicación debe permitir a los usuarios supervisar el estado de los equipos, enviar solicitudes de mantenimiento y seguir el progreso de las reparaciones.
    ```

:::caution[Cuando estás en **Builder**]
El plan **Builder** actualmente no admite UNS, pero los datos simulados están disponibles. Para necesidades de integración de datos más específicas, contacta con nuestro equipo en sales@freezonex.io.
:::
:::tip[Para crear aplicaciones más rápido]
Las plantillas de aplicaciones industriales comunes están disponibles en **Library**. Puedes usar una plantilla y modificar sus funciones para crear una aplicación mucho más rápido.
:::

### Control de acceso
El control de acceso basado en roles se aplica tanto al project como a la aplicación.

- Roles del project
    - **Can Edit**: Acceso completo al project, excepto eliminarlo.
    - **Can Launch**: Solo puede ver el project en **Launchpad** y usar las aplicaciones permitidas.
- Roles de la aplicación
    - El agent los genera automáticamente según la lógica de negocio de la aplicación.
    - Solo pueden asignarse después de añadir al usuario como miembro del project.

:::tip[Si quieres asignar tus propios roles]
Indica los roles y el alcance de permisos en el prompt. El agent los comparará con los roles generados automáticamente. Si tu rol entra en conflicto con el rol generado, el agent te pedirá confirmación.
:::
:::caution[La asignación de roles de aplicación es obligatoria]
Para acceder a una aplicación, debes tener roles de aplicación asignados. Incluso el project owner no puede ver la aplicación en **Launchpad** sin roles de aplicación.
:::

### Gestión de versiones
Las aplicaciones existen en Tier0 en 3 estados.

- **Draft**: El estado más reciente de la aplicación. Los cambios en esta versión no afectan a otras versiones si no se despliega.
- **Snapshot**: Guarda la aplicación en el momento de crear el snapshot. Desplegar una versión snapshot reemplaza la versión **Active** actual.
- **Active**: La versión actual de la aplicación en línea.

:::tip[Cambio de versión]
- Al desplegar un draft, la aplicación active se actualiza a una versión más nueva.
- Al desplegar un snapshot, la aplicación active vuelve a una versión anterior.
:::

### Exportar a entornos externos
Cuando la aplicación esté lista, se puede exportar desde la página **Preview** tanto para terceros externos como para Tier0 Enterprise.

- **Download Source Code**: Exporta el código fuente de la aplicación para desarrollo secundario.
- **Export Bundle**: Exportación específica para importación local en **Tier0 Enterprise**.
