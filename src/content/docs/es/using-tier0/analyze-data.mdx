Marimo Notebook se usa en Tier0 para análisis avanzado de datos con scripts de **Python**, a partir de los datos de fábrica modelados y conectados a UNS.

:::tip[Antes de empezar]
Los datos conectados a modelos UNS con **Enable History** activado están disponibles como una fuente de datos existente en **Notebook**.
:::
<Steps>
1. Los datos UNS están en **VARIABLES** > **PostgreSQL** > **tenant_id** > **uns**.
2. Usa **@** para incluir fuentes de datos al usar **GENERATE WITH AI**. La búsqueda de fuentes de datos admite coincidencia difusa.
3. Guarda versiones de tu análisis para futuros rollbacks.
</Steps>

:::tip[AI assist en Notebook]
- AI assist est? disponible en Tier0 Cloud.
- En Tier0 Enterprise debes proporcionar una key para AI assist.
:::
