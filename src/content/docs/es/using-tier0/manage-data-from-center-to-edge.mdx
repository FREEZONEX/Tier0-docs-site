En una fábrica real, los datos suelen recopilarse mediante dispositivos edge y gestionarse desde un nodo central para reducir el uso del ancho de banda de red y mejorar la seguridad de los datos.
Tier0 ofrece una solución de Fleet Management para gestionar desde un nodo central los datos que se encuentran en los nodos edge.

## Conectar nodos edge al nodo central

<Steps>
1. Primero, crea nodos Fleet en el nodo central.

        :::note
        El número de nodos edge que se pueden conectar depende de la licencia.
        :::
2. Utiliza el token generado por el nodo central para conectar cada nodo edge.
</Steps>

## Sincronizar datos entre el edge y el centro

- Los datos UNS solo se pueden seleccionar y sincronizar desde los nodos edge al nodo central.
- Desde el nodo central, puedes asignar usuarios a los nodos edge para gestionarlos.
