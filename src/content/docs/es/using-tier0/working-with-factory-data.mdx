Puedes operar datos de UNS mediante MQTT y APIs.

## MQTT
Los clientes MQTT pueden conectarse al broker UNS con credenciales generadas en Tier0.
:::note
Puedes usar **MQTTX**, **MQTT Explorer** y **Node-RED** para conectar con el broker y publicar o suscribirte a mensajes.
:::
### Generar credenciales MQTT
Genera credenciales en **Connect** > **Source** > **MQTT Device** y guárdalas.
:::note[Excepción de Tier0 Edge]
Tier0 Edge no requiere credenciales para conexiones externas.
:::
### Conectar clientes MQTT

:::tip
- El broker UNS admite conexiones TCP y WSS con las siguientes direcciones:
    - mqtt://host:1883
    - mqtts://host:8883
    - ws://host:8083/mqtt
    - wss://host:8084/mqtt
- Los siguientes ejemplos usan TCP sin TLS.
:::

<Tabs syncKey="mqtt-client">
  <TabItem label="MQTTX">

1. Instala y abre <a href="https://mqttx.app/" target="_blank" rel="noopener noreferrer">MQTTX</a>.
2. Añade una conexión con la información del broker UNS y las credenciales generadas.
    ```json
    {
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Client ID": "<generated client ID>",
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```

  </TabItem>
  <TabItem label="MQTT Explorer">

1. Instala y abre <a href="https://mqtt-explorer.com/" target="_blank" rel="noopener noreferrer">MQTT Explorer</a>.
2. Añade una nueva conexión con la información del broker UNS y las credenciales generadas.
    ```json
    {
      "Protocol": "mqtt://",
      "Host": "mqtt.tier0.dev",
      "Port": 1883,
      "Username": "<generated username>",
      "Password": "<generated password>"
    }
    ```
3. Antes de conectar, cambia el Client ID por el ID de la credencial en **ADVANCED**.

  </TabItem>
  <TabItem label="Node-RED">
- Usar **Event Flow**: módulo de procesamiento de datos de Tier0 basado en Node-RED.

1. Crea un **Event Flow** en **Flows** y comienza con un nodo `mqtt in`.
2. Selecciona el broker UNS como **Server** (con el mismo nombre que el Flow) y configura **Topic** con un modelo UNS.

- Usar una **instancia independiente de Node-RED**

1. Instala y abre una instancia de <a href="https://nodered.org/docs/getting-started/local" target="_blank" rel="noopener noreferrer">Node-RED</a>.
2. Añade un servidor al nodo `mqtt in` con la siguiente información.
          ```json
          {
            {/* under Connection */}
            "Server": "mqtt://mqtt.tier0.dev",
            "Port": 1883,
            "Client ID": "<generated clientId>",
            {/* under Security */}
            "Username": "<generated username>",
            "Password": "<generated password>"
          }
          ```
  </TabItem>
</Tabs>

### Probar conexiones
<Steps>
1. Comprueba que el estado del cliente sea normal.
2. Copia un Topic de un modelo UNS y publica un mensaje desde el cliente.
</Steps>

## API

### Información básica

- **Base URL**: `https://<your-tier0-host>/openapi/v2`
- **Authentication**: Envía la clave API obtenida en Tier0 en la cabecera `x-api-key`.

### Ejemplos de solicitudes

- `POST /uns/metadata:find` — Enumerar Collections y obtener el ID de Collection
  :::note
  Busca la Collection en `data.items` y copia su `id`. Si no aparece en la primera página, consulta `data.pageInfo` y solicita la siguiente.
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const response = await fetch(`${base}/uns/metadata:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data.items);
  ```

    </TabItem>
    <TabItem label="Python">

  ```python
  import requests

  response = requests.post(
      "https://your-tier0-host/openapi/v2/uns/metadata:find",
      headers={"x-api-key": "your-api-key"},
      json={"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}},
      timeout=30,
  )
  response.raise_for_status()
  result = response.json()
  if result["code"] != 0:
      raise RuntimeError(result.get("error", result.get("msg")))
  print(result["data"]["items"])
  ```

    </TabItem>
    <TabItem label="cURL">

  ```bash
  curl --fail-with-body -X POST "https://your-tier0-host/openapi/v2/uns/metadata:find" \
    -H "content-type: application/json" \
    -H "x-api-key: your-api-key" \
    -d '{"kind": "collection", "filter": {}, "page": {"mode": "offset", "page": 1, "size": 20}}'
  ```

    </TabItem>
  </Tabs>

- `POST /uns/collections/{collectionId}/records:find` — Enumerar Records y obtener el ID de Record
  :::note
  - Sustituye `your-collection-id` por el ID obtenido de `metadata:find`.
  - Busca el Record en `data.items` y copia su `id`. Si no aparece en la primera página, usa `data.pageInfo.nextCursor` como `cursor` de la siguiente solicitud cuando esté disponible.
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/records:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);

  ```

- `POST /uns/collections/{collectionId}/samples:find` — Obtener Samples de un intervalo de tiempo
  :::note
  - Sustituye `your-collection-id` por el ID obtenido de `metadata:find`.
  - Sustituye `record_123` en `recordIds` por el ID de Record obtenido de `records:find`.
  - Configura `from` y `to` con el intervalo deseado.
  - Este ejemplo también filtra por `temperature`. Elimina el filtro si quieres todos los Samples del intervalo o si tu Collection utiliza otro campo.
  :::
  <Tabs syncKey="uns-api-language">
    <TabItem label="JavaScript">

  ```js
  const base = "https://your-tier0-host/openapi/v2";
  const collectionId = "your-collection-id";
  const response = await fetch(`${base}/uns/collections/${encodeURIComponent(collectionId)}/samples:find`, {
    method: "POST",
    headers: { "content-type": "application/json", "x-api-key": "your-api-key" },
    body: JSON.stringify({"recordIds": ["record_123"], "from": 1792454400000, "to": 1792540800000, "filter": {"temperature": {"$gt": 20}}, "limit": 20}),
  });
  const result = await response.json();
  if (!response.ok || result.code !== 0) throw new Error(result.error?.code || result.msg);
  console.log(result.data);
  ```
